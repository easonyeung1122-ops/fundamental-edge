# Module 6：买方建模（The Buy-Side Model）

> 适用范围：搭建与使用买方财务模型——从原始数据录入、行序规范、分析行、预测架构，到指引/一致预期处理、估值输出与 PM 视图。
> 关键定位：**模型是预测工具，是流程的骨干，不是交付物本身。**

## 1. 基础与目的（Foundations, pp.3–7）

### 1.1 两条根本认识（p.3）

1. 当你持有一只股票，你持有的是底层企业的一部分所有权。
2. **股价并不总是准确反映企业的每股价值——这些偏离正是你的机会。**

> Graham："短期来看市场是投票机，长期来看是称重机。"→ **把你的模型与流程当作称重机。** [M6 p.3]

### 1.2 为什么要建模的 6 个理由（p.4）

| # | 理由 | 说明 |
|---|---|---|
| 1 | **深度理解业务** | 培养"所有者知识"（owner's knowledge）；数据是业务的语言，模型是数据的仓库 |
| 2 | **评估业务健康度** | 分析当下经济性：增长、利润率、资本密集度 |
| 3 | **分析业务动能** | 业务在朝正确还是错误方向走？ |
| 4 | **推导独立估值** | 判断当前股价隐含了什么；预测作为估值基础的预测指标 |
| 5 | **识别盈利修正机会** | 找到公司可能超预期/低于一致预期的时点 |
| 6 | **把新闻流放进正确语境** | 建立分析新闻流对 NPV 影响的框架 |

> "为了拥有把新闻流放进正确语境的工具：建立一个分析新闻流对 NPV 影响的框架。" [M6 p.4]

**定位声明（p.5）**：真正的"建模入门"很可能是一门 10–12 小时的课程；华尔街 Prep 与 Training the Street 都是 2 天课程；**本模块是面向买方的"应用型财务建模"**。

**买方模型库（p.6）**：分析师持有一个模型库；视策略不同，或每季度更新，或只在想法有意思时才更新。

## 2. 预测指标（Forecast Metrics, FMs）——建模的终局（p.7）

**股票分析师使用的 4 个主要预测指标**：**Revenue、EBITDA、EPS、Free Cash Flow**。

> **"对这些预测指标施加倍数，是对 DCF 的简写。"**（Applying multiples to these forecast metrics is a shorthand for DCF.）[M6 p.7]

**示意三表（p.7）**

| 科目 | 值 | | 科目 | 值 |
|---|---|---|---|---|
| Revenue | $100 | | Operating Profit | $30 |
| COGS | ($25) | | % margin | 30.0% |
| Gross Profit | $75 | | D&A | $5 |
| % margin | 75.0% | | EBITDA | $35 |
| SG&A | ($30) | | Interest expense | ($5) |
| % of sales | 30.0% | | Pre-Tax Income | $25 |
| R&D | ($10) | | Tax Expense | ($5.0) |
| % of sales | 10.0% | | % rate | 20.0% |
| D&A | ($5) | | Net Income | $20 |
| % of sales | 5.0% | | Diluted Shares | 20 |
| Total Opex | ($45) | | **EPS** | **$1.00** |
| % of sales | 45.0% | | Operating Cash Flow | $15 |
| | | | Capex | ($5) |
| | | | **Free Cash Flow** | **$10** |

### 2.1 选股者的会计速查（pp.8–9）

| 科目 | 定义 |
|---|---|
| Revenue | 销售额，通常 = 数量 × 价格，在扣除费用、折扣与退货净额之前 |
| COGS | 生产商品的直接成本；直接材料与人工，不含分销与销售队伍等间接费用 |
| Gross Profit | Revenue − COGS |
| SG&A | 日常经营费用，非直接成本 |
| R&D | 研发费用 |
| D&A | 资产在其寿命期内的渐进消耗——**非现金费用；资本开支不是 P&L 科目** |
| Total Opex | SG&A + R&D + D&A |
| Operating Profit | COGS 与 opex 之后的营业利润 |
| Interest expense | 债务成本 |
| Pre-tax income | 营业利润减去利息及其他线下项目 |
| Tax expense | 按税前利润的税率计算 |
| Net Income | 税后利润 |
| Diluted shares | 含期权的稀释影响 |
| EPS | 净利润 ÷ 稀释股数 |
| EBITDA | 营业利润 + D&A；税前、息前、资本开支前，替代净利润的指标 |
| Free Cash Flow | "公司所有者（也就是你）有权索取的现金" |

## 3. P/E 滚动框架（P/E Roll-Forward Framework, pp.10–13）

### 3.1 恒等式（p.10）

```
Price (Today)      = NTM P/E  × NTM EPS
Price (T+12 months) = NTM2 P/E × NTM2 EPS
Price (T+36 months) = NTM4 P/E × NTM4 EPS
```
- NTM = "next 12 months"（未来 12 个月）。
- 框架前提：**股票按未来四个季度的估算定价**。
- 预测股价，必须准确预测：12 个月后的 P/E 在哪，以及 12 个月后的 NTM EPS 在哪。
- 论点的 EPS 情形建立在 **"远期年份"（out year）EPS 估算** 之上，而这来自模型构造 + 深度研究，体现于模型的关键驱动部分。[M6 p.11]

### 3.2 目标价构造（p.11）

| 情形 | EPS | 目标 P/E | 目标 | % 回报 | 倍数 | IRR |
|---|---|---|---|---|---|---|
| 3 年目标 | 2026 EPS $32.89 | 20.0x | $657.71 | 173.3% | 2.7x | 39.8% |
| 12 个月基准目标 | 2024 EPS $28.30 | 22.0x | EOY $622.62 | 158.7% | 2.6x | — |
| 12 个月风险情形 | 2021 EPS $9.00 | 18.0x | 未来 12 个月风险 $162.00 | (32.7%) | — | — |

### 3.3 股权定价的混乱现实（pp.12–13）

- "市场极度偏短期"——对，但不完全是。
- **股票被定价为对 30 年以上 FCF 生成的集体预期**，但**交易（常常很暴力）于被用来做外推的短期数据点**。
- **17x P/E 股票的折现 FCF 覆盖 EV 的比例**：**第 1 年仅 4%，到第 30 年才升到约 79%**。
- **"如果只有 4% 的 EV 是今年的 FCF，为什么下个季度这么重要？"**
- **"估值是对长期 FCF 生成的观点。"**（Valuation is a point of view on long term FCF generation.）[M6 p.13]

### 3.4 三表模型行序样例（p.12，10 个预测年）

```
Revenue → % yoy → Operating Profit → % margin → bps yoy → % yoy → Tax Rate 25.0%
→ NOPAT → Interest Expense → Pre-Tax Income → Tax Expense → Net Income
→ Diluted Shares 150,000 → Diluted EPS → % yoy → Invested Capital → YOY Change in IC
→ ROIC → Increase in IC 4.5% → Capital Expenditure → % of revenue 2.5%
→ Free Cash Flow → % margin → FCF/Share → Discount Rate 7.5% → Discounted FCF
```
**DCF 区块**：Discounted FCF $1,654,107 → Terminal Value $439,427 → Net Present Value $2,093,535 → Terminal Multiple 10.0x → WACC 8.0% → Enterprise Value $2,093,535 → Less: Net Debt $732,737 → Market Cap $1,360,797 → Diluted Shares 150,000 → **Price $9.07 → EPS $0.53 → P/E 17.1x**

## 4. 模型构建与格式规范（pp.14–23）

### 4.1 为什么格式重要（p.14）

一致的、逻辑清晰的、易于导航的模型很重要——**一个 PM 可能覆盖 200 多只股票**；建立一套标准格式模板并坚持使用。

### 4.2 格式规范（pp.15, 22）

| 规范 | 说明 |
|---|---|
| 费用/亏损用负数 | 括号表示，行可以直接相加 |
| 单位统一 | 统一用百万（millions） |
| 小数位一致 | 所有数字统一小数位 |
| 美元符号 | 指标以美元计价时带 $ |
| **蓝色字体** | 输入项：非货币的历史数据 + 未来的关键驱动预测 |
| **绿色字体** | 链接公式 |
| 期末日期与天数 | 每个期间标明期末日与天数（销售天数会影响数据） |

### 4.3 数据录入流程（p.15）

- **手工录入 10 年历史的 P&L、BS、CF，并至少 5 年季度数据**。
- 季度按顺序排列，列可隐藏。
- 把干净的利润率指标与底层有机增长拆开。
- **在每个指标下方加一行，记录指引与最近一次指引更新时间。**
- 把 10-Q、10-K、投资者演示、新闻稿中能找到的**每一个财务统计量都录入**。
- 录入行业层面数据、季度宏观数据（若相关且有相关性）。

### 4.4 自上而下的流向（p.15）

```
数据输入（可隐藏） → 经营数据 → 分部 → P&L → 资产负债表 → 现金流量表
```
> "视复杂度而定，把所有数据录在'data inputs'区，再链接到其他区——更新复杂模型时这能省下巨量时间。" [M6 p.15]

### 4.5 单元格批注（p.15）

给关键历史数字与关键未来假设加单元格批注；从公司会议或财报电话会中摘取支持假设的评论；把你对关键驱动的思考写进批注。

### 4.6 模型的六个关键分区（p.15）

| 分区 | 要点 |
|---|---|
| **收入增长** | 把 yoy 增长拆成成分：% 来自销量、% 来自价格、% 来自有机、% 来自并购；2 年与 3 年堆叠收入增长，看 run-rate 增长并做基数正常化；% qoq 与历史平均季节性对照作为另一项检验；**把大额一次性合同同时以 $ 和 % 两种口径放入**，避免扭曲基准与趋势 |
| **成本结构项** | 可变项建模为收入 %，由 bps yoy 驱动；固定或半固定项用 $ yoy / 通胀 / 增长预测；去 10-K 找颗粒度更细的成本拆解 |
| **利润率项** | 注意去年同季的一次性项目，剔除后做干净比较；把 bps qoq 与历史平均利润率季节性对照；看增量利润率趋势（利润 yoy $ 增量 ÷ 收入 yoy $ 增量）；研究历史利润率行为——**管理层是让上行流向利润表底部，还是在毛利率强劲时加大 R&D？预测真实世界的行为** |
| **单位经济** | 每家医院的 EBITDA、每家门店的收入、每名员工的 SG&A；看趋势以发现别人没看到的——SG&A/员工是否因涨薪而飙升？管理层下季度能再抵消吗？ |
| **季节性** | 看历史上每个季度贡献全年 EPS/EBITDA/Revenue 的百分比；许多公司不按季度指引，因此典型季节性是好的起点 |

### 4.7 Excel 模板清单（p.23）

- 年份列用浅灰色（与季度区分）。
- 清楚标明期末日与期间天数（闰年、应付天数）。
- 年份之后加一行 mini-row（便于快速导航与视觉分隔年份）。
- 已报告期间的日期用黑色，未报告期间的日期用浅蓝色（一眼看出模型是否已更新）。
- 隐藏的季度行 + 按钮。
- 控制空格高亮列，Shift+Right 高亮多列，Alt+DGG 组合列。
- 所有列宽完全一致（Alt-HOW 设置，方向键复制）。
- 格式宏："买方 OG 们曾用 TTS turbo；如今 Macabus 很流行。"

### 4.9 原始搭建：TSLA 六步法（pp.20–32）

| 步骤 | 内容 | 页码 |
|---|---|---|
| **Step 1** | 收集构建模型所需的全部原始信息并归档到 TSLA 文件夹：10-K 与 10-Q；财报电话会纪要；投资者活动纪要；投资者 PPT。**前置批处理能让模型构建与打磨高效得多** | p.20 |
| **Step 1 续** | 仔细分析披露内容。SEC 申报是标准化的，但公司披露方式各异。**新闻稿常常披露 10-Q 里没有的信息（往往是调整后指标）；SEC 对 K 和 Q 审查更严，PR 的自由度更大。**检查 IR 网站上的一次性分部重述（重述通常给你过去 4–12 个季度）与其他披露 | p.21 |

### 4.10 分析行规范（pp.29–30）

**收入分析行（p.29）**
| 分析行 | 用途 |
|---|---|
| % yoy | 观察与表达收入的标准方式 |
| % 2 year（2 年堆叠） | 消除异常基数的影响 |
| % 3 year | 有时使用，疫情期间更常见 |
| % qoq | 环比增长 |
| 历史季节性 | 用于与当前对比 |
| 收入增长拆解行集 | `% yoy - CC 8.0%｜% yoy - FX 2.0%｜% M&A 5.0%｜% Organic 3.0%｜% yoy - price/mix 6.0%｜% yoy - volume 2.0%` |

**费用/利润率分析行（p.30）**
- 费用项：% of sales；"bps" yoy（100 bps = 1%；"bipps"是利润率变动最常用的表达）；% yoy
- 利润率项：% margin；bps yoy；% yoy；**增量利润率（Incremental margin）**

### 4.11 重述与 GAAP/Non-GAAP（pp.33–34）

- **重述最佳实践（p.33）**：保留旧的披露口径以观察历史业务轨迹；清楚标注报告口径的变化；在下方叠加新的披露口径，并**用新口径驱动模型**。
- **GAAP 还是 Non-GAAP？（p.34）**：NVST 示例。

### 4.12 PM 视图（The PM View, p.35）

PM 想看到 7 件事：
1. **这只股票有多大 / 流动性如何**
2. **风险回报**
3. **增长轨迹**
4. **利润率轨迹**
5. **EPS "算法"**
6. **方差（Variance）**
7. **估值**

| 12 | **资产负债表（Balance sheet）** | 现金、短期/长期债务、净债务、营运资本、股东权益 | p.80–81 |
| 13 | **杠杆（Leverage）** | Net Debt/TTM EBITDA、12 个月前瞻净债务/TTM EBITDA、FCF/利息费用、契约（Covenant）、下一笔债务到期 | p.81 |
| 14 | **ROIC 区块** | Invested Capital → YOY Change in IC → ROIC → Increase in IC（再投资假设） | p.12, p.77 |
| 15 | **现金流量表（Cash flow statement）** | 经营现金流（营运资本变动前）、营运资本变动、资本开支（% of revenue）、融资活动 | p.82 |
| 16 | **FCF 区块** | Free Cash Flow、% margin、FCF/Share、Discount Rate、Discounted FCF；DCF 区块（Terminal Value、NPV、EV、Net Debt、Market Cap、Price、EPS、P/E） | p.12, p.82 |
| 17 | **校验（Checks）** | 三大表勾稽校验、DCF 与倍数输出一致性校验、股数与 EPS 一致性校验 | p.80–83（各表输出必须闭合的隐含要求） |

**配套 DCF 区块行序（p.12, p.77）**
```
Discounted FCF → Terminal Value → Net Present Value → Terminal Multiple 10.0x
→ WACC 8.0% → Enterprise Value → Less: Net Debt → Market Cap
→ Diluted Shares → Price → EPS → P/E
```

**校验区块应包含的检查（由各表输出闭合性推得）**
- 现金流量表的期末现金 == 资产负债表的现金（三大表勾稽）
- FCF 区块的 FCF == 现金流量表口径 FCF（口径一致性）
- 净债务 == 总债务 − 总现金（与资产负债表一致）
- P/E == Price ÷ EPS（与倍数输出一致）
- 股数变化 == 期初股数 − 回购股数（与 EPS 行一致）

## 6. 九大预测框架（THE 9 FORECASTING FRAMEWORKS, p.43）

> 概述位置 p.43；各框架分述 pp.44–62。

### 框架 1：增长堆叠（GROWTH STACK, p.44）

- **是什么**：GDP 堆叠；许多行业预测的基础；行业协会发布的行业预测是不错的起点；通常基于历史趋势外推和/或调研。
- **两个核心问题**：总消费量的增长率是多少？钱包份额的增长率是多少？
- **搭建示例**
```
人口增长 1.0% + 实际 GDP 增长 2.0% + 通胀 2.0% = 名义 GDP 增长 4.0%
名义 GDP 增长 4.0% + 钱包份额顺风 2.0% = 行业增长 6.0%
```
- **应用**：XYZ Burgers（虚构汉堡制造商）——人口、吃人造肉比例、人口×比例、份额、销量、价格年提、收入预测的全量表（2019–2025）。[M6 p.45]

### 框架 2：混合加速器（MIX ACCELERATOR, p.46）

- **是什么**：两个分部（慢 + 快）的增长差驱动总收入增长加速。
- **示例（10 期）**：慢分部 $900 起，% yoy 3.0%，占总收入 90.0% → 61.2%；快分部 $100 起，% yoy 25.0%，占比 10.0% → 38.8%；总收入 $1,000 → $1,919，增速 5.2% → 10.6%。
- **应用**：生物制品；中国/新兴市场加速；医疗器械机器人；Medicare/Medicaid。
- **规则：结构性 HSD/LDD 收入增长的生意，其 P/E 倍数高于 MSD 生意；拆分部动态以预测这种切换。**

### 框架 3：同店瀑布（COMP WATERFALL, pp.47–49）

- **是什么**：把同店贡献与新店爬坡贡献分别建模，再加总得到总同店影响曲线。
- **Fundamental Edge 披萨单位经济（p.47）**：披萨售出 25,000 / 50,000 / 75,000 / 100,000 / 105,000（% yoy 100.0% / 50.0% / 33.3% / 5.0%）；每月 2,083 / 4,167 / 6,250 / 8,333 / 8,750；每天 68 / 137 / 205 / 274 / 288；单价 $10.00 不变；总收入 $250,000 → $1,050,000。
- **瀑布规则（p.48）**："Same"（同店）永远贡献 5.0% comp；每个"New"（新店）爬坡在第 1 年贡献 25.0%、第 2 年 8.3%、此后 5.0%。
- **结果（p.49）**：总 comp 影响曲线 = **5.0%, 8.3%, 10.7%, 12.5%, 11.7%, 11.0%, 9.0%, 7.0%, 5.0%, 5.0%, …**（新店爬坡随基数扩大而稀释同店贡献）。

### 框架 4：箱式复制器（BOX REPLICATOR, p.50）

- **是什么**：理解每个单元的单位经济/收入/利润；核心问题是：**能有多少个箱？**经济性能否在增长/蚕食下维持？
- **示例**：EBITDA/箱 恒定 $0.250；箱数 10 / 15 / 20 / 25 / 30 / 35；EBITDA $2.5 / $3.8 / $5.0 / $6.3 / $7.5 / $8.8。

### 框架 5：爬坡曲线（RAMP CURVE, p.51）

- **是什么**：适用于生物科技、电动车、社交媒体——研究可比产品的放量速度。
- **做法**：看 FB 达到 10 亿美元用了多久；不同药物上市后的爬坡速度。
- **示例**：Drug 1/2/3/4 各年数值，**Average $16 → $30 → $44 → $71 → $86 → $98**，用于给"Target Drug"建模。

### 框架 6：创造性滞后（CREATIVE LAGS, p.52）

- **是什么**：需求由一个受人口/生命周期驱动的源头产生，存在长滞后；用源头年份 + 滞后来推。
- **SCI 示例**：出生率周期——峰值出生年 1920（3.0）；谷值 1933（2.3，较峰值 (23.3%)）；恢复至 1953（4.1，+36.7%）；**从峰值出生年到回声效应开始的滞后为 85 年**；滞后映射：1999 = 1920 + 79，直至 2038 = 1953 + 85。2014 年前后"减速刚刚开始"，2023 年前后"开始回升"。

### 框架 7：混合外推（MIX EXTRAPOLATION, pp.53–55）

- **是什么**：用更"结构性"的类比市场设定天花板，再映射回本国市场。
- **HCA 示例（p.53）**：分部收入 2019–2027E 与 2019–2021 CAGR —— Medicare $10,798/$10,420/$10,447（3.2%）；Managed Medicare $6,452/$6,997/$8,424（13.2%）；Medicaid $1,572/$1,965/$2,290（2.2%）；Managed Medicaid $2,450/$2,621/$3,124（9.5%）；Managed Care and Insurers $26,544/$26,535/$30,295（6.8%）；International $1,162/$1,120/$1,336（3.6%）；Other $2,358/$1,875/$2,836（13.3%）；总收入 $51,336/$51,533/$58,752（7.1%）。利润率假设：Medicare 7.5%、Managed Medicare 5.0%、Medicaid (10.0%)、Managed Medicaid (20.0%)、Commercial Managed Care 35.0%、International 20.0%、Other 20.0%。示意 EBITDA $11,789 → $17,752；利润率 20.1% → 19.5%。
- **SCI 示例（pp.54–55）**：找一个类比——**英国（比美国更具长期性）：70% 的死亡采用火化**；美国很可能（缓慢地）走向同一方向。美国火化率 15%（1985）→ 56%（2025E）；土葬 $10k vs 火化 $2k/场葬礼。估计火化收入占比 9.5% → 18.4%；土葬 90.5% → 81.6%（2007–2014）；土葬率 61.6% → 47.7%，火化 38.4% → 52.3%。

### 框架 8：中周期/历史平均增长（MID-CYCLE / HISTORICAL GROWTH AVERAGE, p.56）

- **是什么**：预测一串增长序列（2%, 4%, 6%, 2%, (2%), 1%, 5%, 6%, 2%, 8%, 9%, ?）中的下一年。
- **"没有标准答案，但有这些考量："**
  - **均值回归可能很强大。10 年平均增长率 3.9%，意味着进入 2021 年要减速 5.1%。**
  - 但过去 5 年公司以 6% 更快增长。
  - 关键问题：收入增长的核心驱动是什么？经济影响有多大？新产品？定价？竞争？业务组合如何演变？（例如 2016 年剥离低增长分部 + 买入高增长分部）

### 框架 9：数据相关性（DATA CORRELATIONS, pp.57–62）

## 7. 收入预测考量（pp.39–42, 63–68）

### 7.1 收入预测通则（p.39）

- 理解增长的底层驱动——**什么可持续？什么有上限？**
- **从多个角度切入**（哪个最具预测力？）：按地域建模；按 销量 × 价格 建模；按产品建模。
- 关注基数（comps）与 2 年堆叠；关注季节性；对高企增长的持久性保持谨慎（基数效应；均值回归）。

### 7.2 收入的优先性（p.40）

- 收入通常是模型中最重要的科目；**多数行业是竞争性的，最终稳定在 10–15% ROIC**。
- **"披萨店经济学"（Pizza Shop Economics）**：Chipotle vs Qdoba —— 债务 $250,000 / 权益 $250,000 / 总投入资本 $500,000。
  - 强需求：收入 $1,000,000，成本结构 ($925,000)，NOPAT $75,000，**ROIC 15.0%**
  - 弱需求：收入 $900,000，成本结构 ($925,000)，NOPAT ($25,000)，**ROIC (5.0%)**

### 7.3 收入增长的来源（pp.41–42）

- 是市场份额提升在驱动一个 MSD 市场的增长吗？股价是否已定价持续 HSD/LDD 增长？竞争者能否止住份额流失？
- **市场份额模型（p.41）**：市场收入 $100 → $163（5% yoy）；市场份额 10.0% → 12.0%（4 年每年 +50bps，之后为 0）；公司收入 $10.0 → $19.5（+10.3%, +10.0%, +9.8%, +9.6%，之后 +5.0%）。
- **定价周期上限（p.42）**：强劲提价可以在一段时间内驱动收入增长，但**通常不如销量驱动的增长持久**。示例：销量 100 → 160（+5% yoy）；单价 $1.00 → $1.33（3 年每年 +10%，之后 0%）；收入 $100 → $213（+13.3%, +15.5%, +15.5%，之后 +5.0%）。

### 7.4 增长的持久性（pp.63–68）

- **AMZN 收入增速（p.63）**：40.6%（2011）逐步降至 9.2%（2027E）；"我在 AMZN 上建模了一个有意义的增速减速。"
- **AMZN 增量收入（p.64）**：**"这些增速需要每年 $70bn+ 的增量收入！！"**（2023E $83,758mm；2027E $75,554mm）
- **维持 10%+ 收入增长的困难（pp.65–66）**：公司变大后，高 ROIC 项目变得更稀有（竞争加剧）；更大的收入基数让高百分比增长更难，市场还会外推。数据：**25% 的公司萎缩；只有 21% 增长 10%+（含并购）；公司有生命周期。**
- **生命周期工作（p.67）**：是快速放量的生意（科技）？还是耐久的放量生意（箱式复制器、WMT）？**餐饮股的做空触发点：50% of TAM。**
- **维持增长（p.68）**：P/E 倍数往往与收入增速相关——**增速放缓时 P/E 通常会裂开**。**持续的 10%+ 收入增长极为罕见，但通常带来非凡的结果**（IDXX/AMZN/TSLA/GOOGL/AAPL/V）。要理解 10 年以上的跑道：长期驱动力是什么？"市场喜欢"TAM 占比小、易于理解份额提升的场景（电商迁移、线上广告迁移、云迁移）。

### 8.5 bps yoy vs. 增量利润率（p.74）

- "更常见的是按 'bps yoy' 建模。**一致的 bps yoy 隐含着不断上升的'增量利润率'。按增量利润率建模更贴近'真实世界'，其结果是 bps yoy 逐步收窄。**"
- 恒定 100bps/年：利润率 10.0% → 20.0%；增量利润率 31.0% → 40.0%（上升）
- 恒定 31% 增量：利润率 10.0% → 18.1%；bps yoy 100 → 95 → 91 → 86 → 82 → 78 → 75 → 71 → 68 → 64（收窄）

## 9. 预测总览：通用流程（pp.37–38）

### 9.1 通用取向（p.37）

1. **初稿预测时忽略一致预期（consensus estimates）**
2. **警惕"曲棍球杆式"预测（hockey-stick forecasts）**，用**均值回归视角**处理远期估算
3. 始终理解**哪些行项目能驱动有意义的盈利上行/下行**

### 9.2 朴素预测流程（Dummy Forecasting Process, p.37）

1. **从一个与历史趋势增长率一致的基准预测起步**——例如公司历史上实现 +4–6% 有机增长、25–50bps 利润率扩张，这通常是合理的起跳点
2. 判断经营条件是在历史趋势线之上还是之下
3. **处于峰值或谷值条件时，预测要向均值回归倾斜**
→ 结果 = 朴素的"dummy"预测

### 9.3 指引评估流程（p.37）

1. 阅读并理解任何季度、年度或长期指引（在财报电话会、指引电话会、会议演讲、分析师日给出）；**仔细听指引中嵌入的假设**
2. 与自己的研究比较——指引假设是激进、保守还是恰当？若与指引不同，**具体分歧点在哪里？**

### 9.4 详细预测流程（p.38）

1. 研究公司对每个科目的评论，了解详细经营条件（需求疲弱但有新产品要来？竞品要上市？）→ 反映到预测中，并把动态写进单元格批注
2. 重点拆解并落子的领域：(1) 有机增长的底层成分；(2) 利润率结构的底层成分——成本增长与增量利润率；(3) 业务的底层现金流循环与现金流用途——**建模真实的现金用途，或回购或并购**
3. 做自己的研究，并反映进预测
4. 在某些关键争论上**采取概率视角**
5. 标出"关键驱动因素"并制定研究计划：哪些可以用渠道调研验证？哪些可以用数据预测？

## 12. 指引与一致预期（pp.84–97）

### 12.1 公司指引（p.84, p.87）

- **定义**：公司对未来财务指标给出的最佳猜测；为给投资者清晰度而提供；**通常（但不总是）采取保守姿态**。
- **长期指引 vs. 年度/季度指引**：长期指引针对特定指标（收入增长、毛利率、EBITDA 利润率），**约等于业务的 3 年目标**。
- **12 月年末公司的指引节奏**：Q3 电话会（通常 11 月）常给出下一年的"逆风/顺风"；Q4 电话会（通常 1–2 月）给出正式指引；有时还有 12 月的指引电话会。
- **首次指引是一场"指引 vs. 一致预期"的游戏。**

**硬指引 vs. 软指引（p.87）**
| 类型 | 定义 | 例子 |
|---|---|---|
| **硬指引（Hard guidance）** | 新闻稿中给出的硬财务指标 | "我们预计今年 EPS 为 $5.00" |
| **软指引（Soft guidance）** | 通常在财报电话会、投资者演示或 NDR（non-deal roadshow）中对关键驱动的方向性表述 | "Q2 应该是毛利率低点，我们预计 Q3 与 Q4 环比改善" |

- **"关注软指引是'对冲基金式打法'的关键部分。"**
- **指引流程**：在分析模板里建一个指引区，写下硬指引与软指引；在模型里相关科目的下方加一行，承载硬指引与软指引。

### 12.2 一致预期（p.88）—— NFLX 示例

- 13 家机构对 '23 EPS 的估算，从 **$12.84（Canaccord Genuity）到 $9.49（Rosenblatt）——26% 的差距**（Street High vs. Low 26.1%）。
- 一致预期 $10.87；2022/10/7 股价 $224.75；**P/E，Street High 17.5x；P/E，Street Low 23.7x；P/E，一致预期 20.7x**。
- **"通常 P/E 倍数是按一致预期报价的，但 P/E 里的'E'很关键。"**

完整估算表：Canaccord Genuity $12.84；Raymond James $12.41；Guggenheim Securities $11.96；Jefferies $11.84；Monness, Crespi, Hardt $11.19；Restricted 2 $10.65；Truist Securities $10.63；Restricted 1 $10.49；Wolfe Research $10.38；Cowen & Company $10.09；Restricted 3 $9.83；Deutsche Bank Research $9.52；Rosenblatt Securities $9.49。

### 12.3 什么是修正（Revision, p.89）

- 修正 = 一致预期 EPS（或收入、EBITDA）的变化。
- **为什么重要**：最常见的估值框架是 P/E × EPS。若股票交易在 $20（即 20x P/E，EPS $1），EPS 被砍到 $0.50 且 20x 保持，**股价就按 EPS 降幅同幅下跌（本例 50%）**。

### 12.4 修正猎取（Revision Hunting, p.90）

- 通常发生在季度附近，但不总是。
- 理解指引周期——一年中的什么时候。
- **理解首次指引的历史偏向（即通常有 5–7% 的上行缓冲）。**
- 理解 Q1 与 Q3 财报的差异（"创可贴撕除器" band-aid ripper）——**猎取曲棍球杆式指引**。
- 看基本面上的盈利变动基率。
- 看管理层未达指引的倾向性。

### 12.5 修正方法（p.93）

- 识别被 P/E 资本化的 EPS 的重大变化；**修正通常在财报季前后显现**。
- **GRUB 示例**：2019 年 10 月价格 $55.0 / EPS $1.63 / P/E 33.7x → 2019 年 11 月价格 $34.0 / EPS $0.30 / P/E 113.3x；变动 (38.2%) / (81.6%)——**因一次大幅负向修正，股价单日下跌约 40%**。

### 12.6 卖方分析师的角色（pp.94–95）

- 覆盖一个板块，通常 **15–25 只股票**；为所有公司建模型并预测盈利；**"一致预期"就是这些提交的估算的平均值**；给买卖评级；组织管理层会议（NDR）；见买方客户；办年度会议。
- 成功的驱动：Institutional Investor 投票——本质上就是"对买方客户非常有用"。
- 买方投票/付费买什么：公司访问/管理层会议；帮助理解行业动态；有时是荐股；有时是估算。
- **结论：卖方股票研究是客户服务角色。**
- 什么会让买方不快：降级他们持有的股票（尤其理由不充分时）；拿不到管理层会议的访问权。
- **惹恼管理层最快的两件事**：(1) 给卖出评级；(2) 有一个离群的 EPS 估算（特别是为了支撑卖出评级而给得过低）。离群估算要么让"造超预期"更难（太高），要么制造下行风险情形的恐慌（太低）→ **"抱团共识"的制度性偏差（consensus hugging）**；多数卖方拿一致预期加五美分或减五美分。

### 12.7 卖方估算准确性的局限（p.96）

1. **对估算准确性几乎无激励**（第一根胡萝卜是 Institutional Investor 投票——这是份销售工作）
2. **有向指引（± 五美分）靠拢的压力**，来自公司与客户
3. **更新估算的审批流程造成惯性**
4. **模型架构普遍简单，限制了效用**
5. **普遍缺乏另类数据访问**

### 12.8 提升准确性的 7 个"技巧"（p.96）

1. **更规律地更新估算**——基于管理层的中期更新、8-K 披露、外部数据进展
2. **颗粒化的收入预测**——**令人意外地，多数卖方模型只有一行收入预测**；用价格/销量拆解、分部拆解、有机 vs. 并购拆解
3. **盈利的季节性**——例如通常 Q1 占净利润的 30%，但市场本期只预期全年的 25%；**Q2 之后陡峭的 Q3/Q4 爬坡，是盈利下调风险上升的先兆（很多空头在 Q3 付代价）**
4. **历史"超指引"比例**——**公司通常给出的门槛偏低、留有上行空间**
5. **有机增长均值回归框架**——把前瞻有机增长建模在 5 年平均区间内
6. **增量利润率盈利能力框架**——以新增收入上的增量利润率建模盈利能力，而不是总利润率的 bps 扩张
7. **建模资本配置**——不要让现金在资产负债表上堆积，而是建模现金用于回购与补强并购的部署

### 12.9 一致预期：DGX 示例（p.97）

指引区间 $7.50–$9.00（均值 $8.25）；$8.66 均值；**17 位分析师中只有 3 位的估算落在区间之外**（且 Morningstar 与 Wolfe 并非核心卖方/股票发行机构）；作者自己的估算：**$12.50**。

| 季节性检查 | 通常 Q1 ≈ 净利润的 30%；Q2 之后陡峭的 Q3/Q4 爬坡预示盈利下调风险上升 | [M6 p.96] |

## 常见错误与陷阱

- **把建模当目的本身**——模型是预测工具，不是交付物。[M6 p.19, p.84]
- **初稿就锚定一致预期**——先忽略一致预期，再形成自己的观点。[M6 p.37]
- **曲棍球杆式预测**——用均值回归视角对待远期估算。[M6 p.37]
- **把峰值/谷值条件当成永久**——预测要向均值回归倾斜。[M6 p.37]
- **没有"建模到现实"**——例如让总部成本与收入同步增长，或忽略收入下滑时 CFO 会削减营销。[M6 p.75]
- **假设恒定 bps yoy 路径**——它隐含不断上升的增量利润率；应按增量利润率建模。[M6 p.74]
- **同等对待价格驱动与销量驱动的增长**——价格增长对利润率更值钱。[M6 p.73]
- **低估维持 10%+ 增长的难度**——AMZN 需要每年 $70bn+ 的增量收入；只有约 21% 的公司增长 10%+。[M6 pp.64, 66]
- **FCF 不做正常化**——资本开支周期、营运资本、利润率、NOL 都会干扰。[M6 p.82]
- **让现金堆在资产负债表上**——应建模回购与补强并购的部署。[M6 p.96]
- **只有一行收入预测**（多数卖方模型的缺陷）——应做价格/销量、分部或有机/并购拆解。[M6 p.96]
- **忽略软指引**——这是"对冲基金式打法"的关键部分。[M6 p.87]
- **忽略 P/E 里的"E"**——NFLX '23 EPS 估算 26% 的分歧意味着 P/E 可以被报成 17.5x、20.7x 或 23.7x。[M6 p.88]
- **低估修正的量级**——GRUB：EPS (81.6%) 驱动单日 (38.2%) 的股价变动。[M6 p.93]
- **把一致预期当作准确性信号**——卖方几乎没有准确性激励（抱团 ± 五美分）、更新有惯性。[M6 pp.94–96]
- **格式拙劣**——PM 覆盖 200 多只股票，无法导航一个随意的模型。[M6 p.14]
- **不使用单元格批注**——丢失假设的来源与依据。[M6 p.15]
- **漏掉"3 个关键驱动"**——迷失在 800 行模型里。[M6 p.76]
- **不处理重述与 GAAP/non-GAAP**——保留旧口径却不标注变化，会破坏历史轨迹。[M6 p.33]
