# 07 — 评估预期（Assessing Expectations）

> 对应课程：Fundamental Edge 买方培训 Module 10（82 页）。

---

## 1. 核心框架（Framework）

### 1.1 主方程：预期差（The Expectations Gap）

```
EXPECTATIONS GAP = MARKET VIEW − INTERNAL VIEW
（预期差 = 市场观点 − 内部观点）
```

图纸逻辑 `[M10 p.4]`：

```
市场股价 ──► 市场隐含观点（Market-Implied View, MIC）
              「基于对关键驱动因子的隐含假设得到的隐含价值」
      │                                    │
      └──────────► 预期差 EXPECTATIONS GAP ◄┘
                          │
                          ▼
            预期公允价值（Expected Fair Value）
            「基于内部观点对关键驱动因子的假设得到的价值」
```

- **alpha 的全部来源在"价格 vs 价值"的缺口上** `[M10 p.11]`。
- **"看得清楚现实还不够，市场也必须同样看清现实。"**（Credit Suisse）`[M10 p.10]`
- 链条：价格 = 一份 FCF 预测 → 预测 = 一组预期 → 大资金按自己的内部预期买入 → 预期变化时大资金买卖 → 价格变动是预期变动的结果 `[M10 p.12]`。
- **"超预期"如何创造 alpha** `[M10 p.13]`：业绩超预期 → 预期棘轮式上调 → 价格上行 → 价格/价值缺口收敛。**"公理上，一笔成功投资就是超预期。"**
- **长期股权的估值本质** `[M10 p.9, p.11]`：一只标准股票需要 **25–35 年**的 FCF 折现才能达到今天的价格。
- **20x P/E 股票的价值分布** `[M10 p.7]`：第 0–5 年占 **14%**，第 5–15 年占 **26%**，**第 15 年及以后占 60%** → 市场实际上在为远期定价。
- NFLX "% of Enterprise Value Covered, by year" 佐证 `[M10 p.42]`：第 1 年 2%、第 2 年 4%、第 3 年 9%、第 4 年 14%、第 5 年 18% …… 第 30 年 87%。**"股票在不同价位问不同的问题。"**

### 1.2 预期的六个维度 `[M10 p.14]`

| # | 维度 | 说明 |
|---|---|---|
| 1 | 管理层指引（Management guidance） | 公司对前瞻财务指标的官方口径 |
| 2 | 卖方一致预期（Sell-side consensus） | 可知但只是代理 |
| 3 | 叙事（Narrative） | 投资者讲的故事 |
| 4 | 价格隐含预期（Price implied expectations） | 反向 DCF / 反向 P/E 读出的数字 |
| 5 | 买方耳语（Buy-side whisper） | 实际被持有的、超越一致预期的数字 |
| 6 | 投资者持仓（Investor positioning） | 谁在买、为什么买 |

**预期的代理指标** `[M10 p.17]`：卖方一致预期；价格隐含预期；可观察的投资叙事；模型联动（什么在驱动股价）；买方估计/买方耳语；所有权（13F）与持仓结构。

### 1.3 门槛是怎么被设定的：三种机制 `[M10 p.18]`

**(a) 公司沟通（Corporate communications）** `[M10 p.21]`：10Q/10K/8K；业绩电话会；投资者日；投资者会议；"管理层语气"；正式指引。

- *管理层指引* = 公司对前瞻财务指标的最佳猜测，目的是给投资者清晰度；**通常（但并非总是）偏保守** `[M10 p.22]`。
- **长期指引** ≈ 3 年目标（收入增速、毛利率、EBITDA 利润率等）；**年度/季度指引**：Q3 电话会（通常 11 月）常给出次年的"逆风/顺风"；Q4 电话会（通常 1–2 月）给出正式指引；有时还有 12 月的指引电话会。
- **首次指引是一场"指引 vs 一致预期"的游戏。**
- **"硬指引" vs "软指引"**：硬指引 = 新闻稿里的确定数字；软指引 = 电话会口头表述 `[M10 p.22]`。

NVDA 指引 P&L 样例 `[M10 p.23]`（Mid / Low / High）：Revenue $16,000 / $15,680 / $16,320；Gross Profit $11,600 (72.5%) / $11,290 (72.0%) / $11,914 (73.0%)；OpEx ($2,000)；Operating Profit $9,600 (60.0%)；Pre-Tax $9,700；Tax ($1,407) @ 14.5%；Net Income $8,294；Diluted shares 2,500；**隐含 EPS 指引 $3.32 / $3.17 / $3.46**；Consensus 9.19.23 = $3.31。

**(b) 卖方机制（The sell-side mechanism）** `[M10 p.24]`：深度覆盖一个板块（首次覆盖报告、所有重大事件的点评）；提交 buy/hold/sell 评级；提交估计值汇总成一致预期；举办 corporate access 活动/管理层访谈。
- **卖方如何赚钱**：客户佣金 / **季度投票——机构投资者投票是决定性的**。
- *一致预期*：每位分析师把估计值提交给汇总机构，汇总平均。**常与管理层指引重叠** `[M10 p.25]`。
- NVDA 30 位分析师表 `[M10 p.25]`：Q3 EPS 分歧 **$3.28–$3.69**，目标价分歧 **$535–$1,100**（含若干 "Restricted"）。

**(c) 投资者行为（Investor behavior）** `[M10 p.63–65]`：谁在买、为什么买——主题 ETF、单基金经理、量化、纯多头、指数化、散户日内交易、宏观投资者、多策略管理人。同一只股票、不同理由："满足指数门槛"、"喜欢新管理层"、"下注表达宏观观点"、"表达主题观点"、"统计性均值回归"、"喜欢利润率故事"、"喜欢业绩布局"、"新产品令人兴奋"。

### 1.4 半公开信息与意外因子（Surprise Factor）`[M10 p.19–20]`

- 老交易员说法：**"已经在新闻里的，就已经在价格里。"**
- 公开信息不太可能成为单一 alpha 路径。真正的路径：
  1. **半公开信息**——展会见闻、行业顾问、同业映射（read-through）、与管理层会议、定制化分析
  2. **马赛克法（Mosaic approach）**——广泛且穷尽的信息收集 → 提炼出正确且有差异化的洞见
  3. **模式识别（Pattern recognition）**——"我们以前见过这个故事"
  4. **不对称性（Asymmetry）**——识别出有吸引力的前瞻风险/回报
- **正确且具前瞻性的判断必然包含一个"意外因子"，它把价格棘轮式推向你的方向。**

### 1.5 叙事（Narrative）

- **定义** `[M10 p.33]`：投资者在讲的故事；捕捉当前情绪与对未来的普遍预期。**"P/E 只是一个故事，一组预期。"**
- **影响叙事的因素** `[M10 p.35]`：管理层评论；卖方评论；公司与同业财务表现；公司与同业股价形成。**"叙事跟随股价"** → *保持独立思考，不被群体叙事影响*。
- **叙事四阶段** `[M10 p.36]`：

| 阶段 | 含义 |
|---|---|
| 1. 叙事形成（Formation） | 通过"意外因子"/"发现价值"（对体系的冲击：大幅超预期、评论转向）形成新叙事 |
| 2. 叙事验证（Validation） | 增量信息流支撑并验证；观点变成一致预期并"price in"；**常常会超调** |
| 3. 叙事违背（Violation） | 信息流违背一致叙事 → 价格反转；多空激烈辩论数据点；可能变成"knife fight" |
| 4. 叙事反转（Reversal） | 信息流支持一致预期转向旧叙事；新叙事重新形成 |

- **催化剂与叙事** `[M10 p.38]`：大幅波动影响数字或叙事；意外因子把价格棘轮到一组新预期；业务动能反转；管理层信息反转；指引变动。
- META 叙事样例 `[M10 p.37]`："STRUCTURAL WINNER"（~$100 → ~$375）、"DECLINING BUSINESS"（~$88.91）、"AI WINNER"（$470）。

### 1.6 反向 DCF（Reverse DCF）：读出价格隐含了什么 `[M10 p.48]`

**课程自身的建模步骤（Recipe）**：

1. 搭建核心 DCF 架构——**"我喜欢把模型建到 30 年"**（把终值倍数的重要性降到最低，并允许分阶段建模）
2. **每 5 年递减一次收入增速**（基数变大压制百分比增速）
3. **以增量利润率（incremental margin）为基础建模利润率**（这是利润率的天花板）
4. **让投入资本随收入同比例增长**，以维持合理的 ROIC 水平
5. **用市场隐含的 WACC 折现**（在 16x P/E 处，WACC 约为 **8%**），并按风险水平调整
6. **对终值施加"退出增长倍数"（ex-growth multiple）**（**期望低于 NPV 的 25%**）
7. 把隐含 EV 减净债务，与**下一年 EPS** 比较，**倒推公允 P/E**

**Sample Business 反向 DCF 输出** `[M10 p.48]`：Discounted FCF $1,616,027；Terminal Value $460,182；NPV $2,076,209；Terminal Multiple 10.0x；WACC 8.0%；EV $2,076,209；Less Net Debt $726,673；Market Cap $1,349,536；Diluted shares 150,000；**Price $9.00；EPS $0.55；P/E 16.4x**。

**反向 DCF 的取舍** `[M10 p.49]`：
- 这个工具的价值在于**隔离出关键驱动因子**；
- 用卖方作为 bull / bear / base case 的代理；
- 核心问题：**市场相信一致预期吗？**
- 有些情形很难隔离 → **在这些"脏"情形下，反向 P/E 更好用**。

**关键驱动信号表（Key Driver Signal）** `[M10 p.50]`：固定反向 DCF 于当前股价，然后对关键驱动做"滴定"——**"不是一个高度科学的过程，更像是 finger in the air"**：

| 情景 | 5-Yr Member | 5-Yr ARPU | 5-Yr Margin |
|---|---|---|---|
| High | $700 | 15.0% | $16.00 | 35.0% |
| Current | $365 | 6.0% | $15.00 | 25.0% |
| Low | $165 | 0.0% | $13.00 | 21.0% |

### 1.7 盈利能力与反向 P/E（Earnings Power & Reverse P/E）`[M10 p.55]`

- 理论：市场的定价机制在寻找**"正常化盈利能力"（normalized earnings power）**。
- 反向 P/E 步骤：观察价格（$435）→ 观察历史 P/E 区间（**35–45x**）→ **价格 ÷ 历史 P/E = 价格隐含的盈利能力**。

| 历史倍数 | 1 年 Min/Max/Median | 5 年 | 10 年 |
|---|---|---|---|
| Absolute（绝对） | 27.5x / 61.4x / 45.8x | 19.8x / 66.5x / 39.5x | 15.9x / 66.5x / 33.9x |
| S&P relative（相对） | 11.7x / 43.1x / 27.1x | 5.7x / 45.0x / 20.1x | 0.7x / 45.0x / 16.7x |
| 18.7x Implied（隐含） | 30.3x / 61.8x / 45.7x | 24.3x / 63.6x / 38.7x | 19.4x / 63.6x / 35.4x |

- 近期隐含盈利能力：2023/9/18 价格 $438.75；**@45.0x → 隐含 EPS $9.75；@35.0x → 隐含 EPS $12.54**。

### 1.8 错误定价的赔率（Mispriced Odds，赛马比喻）`[M10 p.16, p.54]`

- **"快马：不是最快的马，而是定价错误的赔率。"**
- 例：市场定价 75% / 我认为 65%（慢马）；市场定价 15% / 我认为 35%（快马）。
- 赛马不是找最快的马或最好的骑师，而是：1) 观察赔率；2) 建立分析决定结果概率的流程；3) **在赔率与内部预期不一致处下注**。
- NFLX 表：My View $300 → 从 $700 起算回报 57.1%；从 $165 起算回报 81.8%。

### 1.9 概率树（Probability Tree，多情景）`[M10 p.56]`

- **"股票反映概率"**：股权不是二元事件；股价内嵌概率；概率树高亮出市场定价过于乐观或过于悲观的位置。
- **多头候选**：bear/disaster 情景的下行只是温和的（市场已把最坏情况甚至接近最坏情况计入）。
- **空头候选**：bull 情景已被计入，市场对风险自满。
- **两边都有**：存在便宜/免费的嵌入式期权（optionality）对应的大幅波动。

| Scenario | Target | % return | Prob |
|---|---|---|---|
| Bull Case: Takeout | $100.00 | 100.0% | 10.0% |
| Bull Case | $90.00 | 80.0% | 10.0% |
| Base Case | $80.00 | 60.0% | 50.0% |
| Bear Case | $34.45 | (31.1%) | 20.0% |
| Disaster Case | $25.00 | (50.0%) | 10.0% |
| **Probability-Adjusted** | **$68.39** | **36.8%** | **100.0%** |

### 1.10 PSUC 框架（Probability of Success）`[M10 p.57–58]`

**催化剂评估流程（Catalyst Assessment Process）**：
1. 识别即将到来的催化剂
2. 研究潜在结果
3. 给各结果赋概率
4. 用**概率树**（多结果）或 **PSUC 框架**（二元结果）估算**已经计入股价的部分**
5. 把"已计入的部分"与我们的独立评估对比

**PSUC 公式**：

```
PSUC = (上涨的成功幅度) ÷ (上涨的成功幅度 + |下跌的负面幅度|)
```

| 情景 | Win 幅度 | Loss 幅度 | Reward/Risk | 隐含 PSUC |
|---|---|---|---|---|
| Coin Flip | 10.0% | (10.0%) | 1.0x | 50.0% |
| Typical M&A Arb | 6.0% | (30.0%) | 0.2x | 83.3% |
| 10-to-1 Biotech Bet | 100.0% | (10.0%) | 10.0x | 9.1% |

锚点值：**抛硬币的 PSUC = 50%；LeBron 上篮的 PSUC = 99%。**

**PSUC 三步法**：
1. **估算当前已计入的部分**（艺术 + 科学）。最佳方法：用分部驱动的 DCF 得出一个非催化剂资产的离散价值 → 由此推出催化剂的市场隐含度量。
2. **估算成功结果下的股价变动**（如药物试验成功、新增 $100m 收入、新增 $50m FCF、2030 年专利到期）。把 NPV 折算为当前股价的百分比。**当前股价已计入的部分与 100% PSUC 之间的差额，就是股价变动的代理。**
3. **估算负面结果下的股价变动**——把当前隐含价值归零；也许保留部分看涨期权价值。

### 1.11 买方耳语（Buy-Side Whisper）`[M10 p.67–72]`

- 卖方一致预期是**可知**的；买方一致预期必须被"占卜"（divined）。**没有科学方法收集它**："作为一只股票的大持有人，我会把自己的牌贴在手里"（若论点被打破需要退出流动性；也不想让人知道你要撤）。**"根本不存在什么 Illuminati 式的买方一致预期门户！！"** `[M10 p.69]`
- **公开竞技场框架（Public-arena framework）**（假设较短持有期的投资者会激进地计入催化剂预期）：1. IR 沟通；2. 另类数据/信用卡面板数据（在广泛传播处）；3. 管理层在会议上的评论；4. Tegus 渠道调研笔记；5. 卖方评论。**"仅建立在公开竞技场反馈之上的催化剂型论点是有风险的。"**
- **常见耳语情形** `[M10 p.67]`：公司指引 Q3 同店增长 +5%；过去 6 个季度平均交付比指引高 2%（"sandbagging"）；公司 Q2 提到强劲的"exit rate"；管理层与投资者会议中提到"强劲订单簿"和"终端市场加速"；去年同期是弱对比季度。综合 1–3，基本面投资者把耳语定在 **8–9%**。
- **耳语测算表样例** `[M10 p.68]`：公司指引 SSS 增长 5.0%；过去 6 季平均 7.0%；过去 6 季平均 beat 2.0%；beat 时股价平均变动 1.2%；Q2 exit rate 评论 8.0%；订单簿转强评论 8.5%；隐含另类数据（加速）9.0%；投机性卖盘 "bar" 评论 8.5%；卖方一致预期 SSS 5.2%；**买方耳语 8.5%**。
- **如何评估买方一致预期** `[M10 p.70]`：1. 查 13F，但要知道它**无法捕捉高速度（high-velocity）的市场中性资金**；2. **卖方在谈论它吗？催化剂已被兑现**（"等到 Jefferies 推这个价差的时候，这笔交易已经结束了"）；3. "感觉"上是不是对冲基金都压在这个想法上？会议有多密集？提问的语气如何？直接问卖方分析师：哪些买方想法拥挤/热门。
- **补充渠道** `[M10 p.70]`：卖方"HF hustle"分析师（问销售）；专业销售（活跃的投行服务："这只股票为什么在动"、晨报、内部信息透露哪个 pod 在关注）；卖方主办的午餐/晚宴/预览会（Q&A 的语气是关键，时间花在哪里是关键）；买方同伴网络（但**要低估别人告诉你的程度**）。
- **如何判断"好消息"是否已被计入** `[M10 p.71]`：
  - "好消息"是什么时候被披露的？（8-K、管理层会议、另类数据下载的确切日期）
  - 股价从那个催化剂日起怎么走？（理想情况下看**特质收益（idio move）**，剔除 beta 与长期动量、行业组等因子）
  - 我们得到了正面读数，但股价在进入业绩前已经跑赢 8%？
  - 用**增量主义框架（incrementalism framework）**跑一遍催化剂：它把 DCF 价值、远期 EPS、P/E 假设改变了多少？
  - **"你的估计是正 5–10%？抱歉，那个'好消息'很可能已经被计入了。"**
  - **什么才真的在业绩上赚钱**：一个逆势（counter-trend）赌注，一个意外因子。寻找这样的情形——**股价特质性跑输 5–10%，而你认为催化剂会带来正 5–10% 的结果** → 这个（1）隐含恐惧 +（2）正面前景，构成"pop"（上涨）所必需的预期差前置条件。
- **建立买方网络** `[M10 p.72]`：别害羞，主动介绍自己；把卖方当"社交主席"；请求交换看法（先取得 PM 批准）；先做到乐于助人；友善。

### 1.12 持仓、交易结构与"持仓悖论" `[M10 p.60–66]`

- **持仓悖论（Paradox of positioning）** `[M10 p.60]`：通常拥挤交易的**方向是对的**（许多伟大股票都是一致做多：AAPL、GOOGL、AMZN）；拥挤 = "正 alpha、低 Sharpe"因子。但当人群错了时，**"持仓平仓的痛（pain trade）"非常剧烈**。
- **持仓评估** `[M10 p.65]`：13F 披露（对低换手玩家有效；必须理解滞后）；空头持仓披露（日频数据可识别空头资金流；价格信号；自相关的拥挤股交易日可指示持仓）；高速度玩家（需一线卖方渠道）：与卖方股票销售/专业销售的对话与调研；买方网络/群聊；卖方午餐/观点晚宴；卖方会议上被"点名最多的会议"/"谁在房间里"。
- **交易结构（Sets）** `[M10 p.66]`：好的战术性结构本质上是**逆向的**——股票在市场"改变主意"时大幅波动；**如果一只股票被准确定价、且公司交出一致预期内的结果，那个事件就没有价格变动可来。** 结构要素：一致预期怎么看 vs 你的看法；估值；近期股价表现（在加仓还是减仓）；近期的上调/下调；其他投资者如何持仓。
- **大买家的足迹（The footprint of a (big) buyer）** `[M10 p.62]`：大买家建大仓会造成**逐日向上的滑点**，多名投资者同时新建仓时更严重。滑点考量：订单簿的深度/形状（depth/shape）、自然成交（natural cross）、暗池。示例：市值 $10,000；目标仓位 $500 = 5.0% 持股；ADV $100；目标为日成交量的 10.0%；每日买入 $10；**建仓所需天数 50**；订单簿走到 $55.74 vs 中间价 $55.00 → **滑点 1.3%**。

### 1.13 帕累托式的研究流程 `[M10 p.44–47]`

- **蒸馏过程**：对每一只股票，识别、表述并聚焦 **3 个关键驱动因子**。
- 帕累托金字塔：**所有已知的一切 → 关键驱动（"什么会推动股价"）→ 差异化**。
- **关键驱动类别** `[M10 p.46]`：基于数字（估计值）；基于估值；基于终值感知（GOOGL / AI）；基于算法；基于增长耐久性；基于监管。*"什么会驱动股价的大幅波动？很可能与你的关键驱动绑定。"*
- **关键驱动问题样例** `[M10 p.47]`：政府会不会禁掉营利性医保？这药会不会获批？新产品上市表现如何？谁会拿下这份新合同？Facebook 的 Reels 能否对抗 TikTok？MSFT/ChatGPT 会不会杀死 Google 的金鹅？Amazon 的零售业务会不会终于有合理利润？牙科产品的需求今年会不会回暖？生物科技融资会不会放缓？NFLX 在流媒体战争中表现如何？

### 1.14 差异化（Differentiation）与方差表 `[M10 p.79]`

- NFLX '23 EPS 分歧：**13 个估计，从 $12.84（Canaccord）到 $9.49（Rosenblatt）——26% 的缺口**。一致预期 $10.87；2022/10/7 股价 $224.75。
- "NFLX 是按 17.5x 交易吗？（卖方最高 EPS）" vs "23.7x？（卖方最低 EPS）"——**Street High P/E 17.5x；Street Low P/E 23.7x；Consensus P/E 20.7x**。
- 算例：2022 指引 $1.00 × 20.0x → $20.00；2022 指引下调后 $0.75 × 18.0x → $13.50；**股价变动 (32.5%)**。
- 核心一句：**"一般 P/E 倍数是用一致预期报出的，但 P/E 里的 'E' 才是关键。"**

### 1.15 三个关键论点问题 `[M10 p.80–81]`

1. **"先让我了解情况"**（Get me up to speed on the situation）
2. **"我们在哪里不同，为什么？"**（Where are we different & why?）
3. **"我们靠什么路径拿到钱？"**（What is our path to getting paid?）

第 2 问拆解为 `[M10 p.81]`：识别关键驱动 / 什么已被计入；一致预期与方差表对照卖方；估值与价格隐含预期；多空张力以及我们相信哪一边。

### 1.16 FEV 框架（Fundamentals, Expectations, Valuation）`[M10 p.76]`

**多头 — 基本面**：稳健且加速的收入增长；定价权；利润率扩张机会；成本压力缓解；某种从弱到强的均值回归；新产品贡献强劲且增长；份额机会；强增量利润率；高增量 ROIC（在 EBITDA 加速的同时 capex 稳定或下降）；高资本回报/资本配置机会；有吸引力的 FCF 复利，能够"付钱给我们等待"。

**多头 — 预期**：某个高可见度的投资争议将被化解（**最好伴随催化剂**）或强度随时间衰减；中性或负面的投资者情绪将均值回归；即将到来的季度业绩超预期；对卖方年度估计的正面修正。

**多头 — 估值**：相对内在价值（我们的内部 DCF）便宜；相对最接近的可比公司便宜（**理想情况接近历史价差的谷底水平**）；相对历史便宜（**理想情况接近历史谷底，且经 beta 调整**）；相对 3–5 年增长算法便宜（例：多数 20% EPS 增长股交易在 25–30x P/E，这只在 18x 吗？）。

**空头 — 基本面**：疲弱且恶化的收入增长；定价权走弱；利润率压力；成本压力加剧；从强到弱的均值回归（临时顺风消散）；份额流失；弱增量利润率/峰值利润率（"只有一个方向可走"）；弱增量 ROIC（要维持当前盈利必须加资本开支——"油箱里还有更多油"）；漏桶式资本配置（要靠补强并购才能维持当前利润）；FCF 水平弱且 FCF 增长弱（"承诺明天会拿出 FCF，但当下 FCF 经济性很差"）。

**空头 — 预期**：希望消散（新产品/新举措"在股价里"但很可能失败）；某种当前未被讨论的感知风险，会随着时间变成"难以证伪"的争议（例：自动驾驶对整车厂是逆风）；即将到来的季度业绩不及预期；对卖方年度估计的负面修正。

**空头 — 估值**：相对内在价值（内部 DCF）昂贵；相对最接近的可比公司昂贵（**理想情况接近历史价差的峰值水平**）；相对历史昂贵（**理想情况接近历史峰值，且经 beta 调整**）；相对 3–5 年增长算法昂贵（例：多数 8% EPS 增长股交易在 14–16x，这只在 24x 吗？）。

### 1.17 核心争议模板（Core Debate Template）`[M10 p.77–78]`

- **核心争议类型**：市场规模；结构性轨迹；周期性轨迹；定价轨迹；竞争格局；护城河/进入壁垒；单位经济的可规模化性；现金经济质量；相对同业的盈利能力；企业举措的智慧。
- **可争议的议题**：结构性增长算法；监管的影响；即将到来的催化剂的影响；汇率影响；供应链举措；公允估值；恰当的资本配置；会计计提；业务质量；管理层能力。
- **四格模板**：CORE DEBATE（"什么会推动股价？多空张力是什么？"）→ CONSENSUS VIEW（"当前股价计入了什么情形？"）→ TAILORED ANALYTICS（"我的投资流程认为最可能的结果是什么？"）→ THESIS（"如果存在预期差，这个差距如何收敛？"）。

## 4. 常见错误与陷阱（Common Mistakes / Pitfalls）

1. **把一致预期等同于预期**。"卖方估计只是预期的代理，但并不是对预期的完美封装。预期很重要！！" `[M10 p.26]` —— 这正是"公司超预期但股价下跌"这一经典场景的根源。
2. **相信卖方估计的准确性**。约束条件 `[M10 p.27]`：对估计准确性几乎无激励（**第一位的胡萝卜是机构投资者投票**——本质是销售/客户服务工作）；有压力围绕指引聚集（正负五分钱）；发布流程造成惯性；模型架构通常过于简化；普遍缺乏另类数据。而机构买方可以接触到全部 **20+ 位分析师**并筛选最锋利的观点。
3. **估计值陈旧（Stale estimates）** `[M10 p.30]`：卖方给 $1.00 → 负面消息 → 股价跌 20% → P/E 从 15x 压缩到 12x → "看起来便宜" → 但等估计下调到 $0.80（回到 15x P/E）时，股价并不更便宜。**"卖方估计的变化存在摩擦。"**
4. **漏掉修正（Missing revisions）** `[M10 p.29]`：修正通常在业绩季前后才显现。GRUB：2019/10/19 $55.00 / EPS $1.63 / 33.7x → 2019/11/19 $34.00 / EPS $0.30 / 113.3x → 股价 (38.2%)，EPS (81.6%) → **单日跌约 40%**。
5. **叙事跟随股价**——失去独立思考，被群体叙事带走 `[M10 p.35]`。
6. **只交易公开竞技场**。仅建立在公开竞技场反馈之上的催化剂型论点是有风险的 `[M10 p.69]`。
7. **在"被准确定价 + 交出一致预期结果"的股票上建论点**——那个事件没有价格变动可来 `[M10 p.66]`。
8. **把"正面消息"当成 alpha**。一旦好消息已在价格里（进入业绩前特质性跑赢 8%+），它就不是意外因子 `[M10 p.71]`。
9. **建仓规模错误**——大买家建大仓会造成持续的向上滑点；滑点考量：订单簿深度/形状、自然成交、暗池 `[M10 p.62]`。
10. **把"超预期"与"好投资"混为一谈**——必须先准确评估预期，才能预判一次 beat `[M10 p.13]`。
11. **过度解读叙事阶段**——叙事验证"常常超调"；叙事违背可能变成"knife fight" `[M10 p.36]`。

| 术语 | 课程定义 |

| 预期差（Expectations Gap） | Market View − Internal View；alpha 载荷 / 价格对价值的缺口 |

| 价格隐含预期（Price implied expectations） | 当前价格对关键驱动的说法（反向 DCF / 反向 P/E） |
| 买方耳语（Buy-side whisper） | 买方实际持有的、超越一致预期的数字；只能被"占卜" |
| 反向 DCF（Reverse DCF） | 把模型固定在市场价格上，再隔离出隐含的关键驱动 |
| 反向 P/E（Reverse P/E） | 价格 ÷ 历史 P/E = 价格隐含的（正常化）盈利能力 |
| 盈利能力（Earnings power） | 市场定价机制在寻找的正常化盈利 |
| 关键驱动信号（Key driver signal） | 对 3 个关键驱动做 High/Current/Low 滴定（固定反向 DCF） |
| 错误定价的赔率（Mispriced odds） | 在赔率与内部预期不同处下注（赛马比喻） |
| 意外因子（Surprise factor） | 把价格棘轮到新一组预期的那一下冲击（"发现价值"） |
| 发现价值（Discovery value） | 创造新叙事的新信息 |
| 叙事四阶段 | 形成 / 验证 / 违背 / 反转 |
| 半公开信息（Semi-public information） | 展会、顾问、同业映射、管理层会议、定制分析 |
| 马赛克法（Mosaic approach） | 广泛穷尽的信息收集 → 提炼正确且差异化的洞见 |
| 增量主义框架（Incrementalism framework） | 催化剂把 DCF 价值、远期 EPS、P/E 假设改变了多少 |
| 特质收益（Idio move） | 剔除 beta 与因子（长期动量、行业组）后的股价变动 |
| PSUC | Probability of Success：上涨幅度 ÷ (上涨幅度 + \|下跌幅度\|) |
| 概率树（Probability tree） | 多情景期望值，内嵌概率 |
| 抬门槛的三种机制（Bars） | 公司沟通 / 卖方机制 / 投资者行为 |
| 交易结构（Set-up） | 一致预期 vs 你的观点、估值、股价行为、持仓、评级构成的配置 |
| 持仓悖论（Paradox of positioning） | 拥挤交易通常方向正确，但平仓的痛非常剧烈 |
| 论点工作的向量（Vectors of thesis work） | 基本面工作 / 预期工作 / 估值工作 |
| 方差表（Variance table） | 你的估计 vs 一致预期 —— 差异化的来源 |
| 核心争议（Core debate） | 会推动股价的多空张力 |
