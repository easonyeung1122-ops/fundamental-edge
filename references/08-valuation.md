# 08 — 应用估值（Applied Valuation）

> 对应课程：Fundamental Edge 买方培训 Module 11（154 页）。本模块是全套估值工具箱。

## 1. 核心框架（Framework）

### 1.1 第一性原理：一切都是 DCF（"Everything is a DCF"）

- **价格是一份 FCF 预测**（"Price is a FCF forecast"）`[M11 p.9, p.11]`
- **倍数只是 DCF 的速记**（"Multiples simply 'shorthand' for a DCF"；Mauboussin："everything is a DCF"）`[M11 p.9]`
- **解释性框架只是"框架"** `[M11 p.8]`：
  > "EXPLANATORY FRAMEWORKS ARE JUST 'FRAMEWORKS'. THEY CERTAINLY INFLUENCE INVESTOR BEHAVIOR, BUT INTRINSIC VALUE ISN'T A 'LAW', IT IS A 'PERCEPTION', AND PERCEPTIONS CAN VARY WIDELY."
- 投资者的任务 `[M11 p.2]`：预测股价；因为它会涨而买入；方法不同、目标相同；批判性思考是什么驱动股价。**"我需要对内在价值有清晰的看法，但我也需要别人看到它！"**
- **既有价值观点也有价格观点** `[M11 p.13]`：价值投资者（这门生意值多少？现金流可能是什么样？）vs 动量投资者（股价往哪走？资金流、叙事）。**"现代的、卓越的投资者应该同时对两者都有解释性框架。"**
- 估值股权的困难 `[M11 p.14]`：股权久期；没有合约化的支付流；高失败率（许多归零）；动态竞争；不可预测的外部性。
- **股票定价的混乱现实** `[M11 p.17]`：学术视角——股权 NPV = 无杠杆 FCF 折现值 − 净债务；但对这些现金流的可见度**极低（连 CFO 往往也只有 6–18 个月的可见度）**；可见度有限 ⇒ 集体的长期观点受短期数据点影响；被迫或情绪化的卖方、非基本面卖方（ETF 资金流）、恐慌的卖方。
- 供需决定资产价格（price × quantity 均衡）`[M11 p.16]`。

### 1.2 DCF 机制：预测无杠杆 FCF → 用 WACC 折现 → 加终值

**DCF 101** `[M11 p.10]`：预测 **5 年 FCF** → 对第 6 年施加**终值倍数** → 用 **WACC** 折现。
**Investment Multiples 101**："Multiples are a shortcut to DCF"。投资流程：什么驱动自由现金流（基本面）？什么驱动估值（折现率）？

**基线商业模型（garbage-in-garbage-out baseline business）** `[M11 p.22, p.45]`：典型"市场倍数"型商业——**5–6% 收入增长、8–9% EPS 增长、2.5% 永续增长、8% WACC**。用示意性的稀释股数来把 DCF 翻译成市场倍数（**"切成几片披萨并不重要"**）。

**终值（Terminal Value）** `[M11 p.23, p.46]`：在典型的 5 年预测期 DCF 中，**约 85% 的价值来自终值**。终值有两种做法：**永续增长率法（perpetuity growth rate）** 或 **退出倍数法（exit multiple）**。

**终值增长率敏感性** `[M11 p.24]`——**"50–100bps 可以决定你的估值的生死！"**

**30 年 DCF 的替代方案** `[M11 p.26]`：30 年 DCF 是"荒谬地不精确"（"谁知道这生意 15 年后长什么样"），但它比"3.5% 终值增长"可以被反向推演得**更精确**；它把大部分价值推进 FCF 预测期，而不是押在单一终值增长率上。**这是课件推荐的替代做法：30 年 + 分段递减 + ex-growth 终值倍数。**

**两个估值输入** `[M11 p.26]`：(1) 自由现金流预测；(2) 折现率（倍数的倒数）。
- **倍数**同样"荒谬地不精确"，但可以锚定在 (1) 市场倍数、(2) 行业/可比倍数、(3) 历史倍数 —— 比"这是 7.5% 还是 8.5% WACC"有更多层考虑。

**Gavin Baker 的"两件真事"** `[M11 p.20]`：(1) DCF 是给资产估值的最好方法，其他所有方法都只是捷径；(2) 同时也是真的——**99% 的 PM 不喜欢 DCF**（对资本成本与终值假设极度敏感）。**"如果最好的方法没有用，我们怎么办？？？"**
- 买方听到的话 `[M11 p.21]`："I don't like DCFs. They are garbage in, garbage out."

**股利折现模型（DDM）** `[M11 p.27–29]`：逻辑上成立，但**"在实践中，我见过股利折现模型被用来给一只股票估值，精确的次数是零。"** 股利一般被认为无关紧要（除少数细节，如价值破坏型管理层改变股利政策）。"增量买家（incremental buyer）"分析反映股利政策。
- 资本返还 vs 再投资 `[M11 p.29]`：Market Cap $1,500；Net Debt $0；FCF $100；Shares 150；股价 $10.00；倍数 15.0x。股利路径 → $1,500 + $300 = $1,800 ÷ 150 股 = $12.00；回购路径 → $1,500 + $0 = $1,500 ÷ 125 股 = $12.00；内部再投资 → 第 3 年 FCF $120，价值 $1,800 ÷ 150 股 = $12.00。**每股结果相同，只有混合方式不同。**

**价值创造的晴雨表** `[M11 p.30]`：
> "THE BEST MEASURE OF VALUE CREATION IS THE TRAJECTORY OF FREE CASH FLOW / SHARE."（自由现金流/股的轨迹是衡量价值创造最好的指标。）

### 1.3 资本成本构建（Cost of Capital Build）

**WACC 是"不精确之上的不精确"**，建立在三个不精确的输入之上：无风险利率、Beta、股权风险溢价 `[M11 p.25]`。

```
CAPM: Cost of Equity = Risk free 4.5% + Beta 1.0x × ERP 5.0% = 9.5%

WACC = Cost of Equity 9.5% × E/V 70.0%  +  Debt YTM After Tax 6.0% × D/V 30.0%  = 8.0%
```

**WACC 敏感性** `[M11 p.25]`：

| WACC | Implied P/E | Δ | | WACC | Implied P/E | Δ |
|---|---|---|---|---|---|---|
| 10.0% | 12.3x | (29.7%) | | 7.5% | 19.6x | +12.0% |
| 9.5% | 13.2x | (24.6%) | | 7.0% | 22.5x | +28.6% |
| 9.0% | 14.4x | (17.7%) | | 6.5% | 26.4x | +50.9% |
| 8.5% | 15.8x | (9.7%) | | 6.0% | 32.1x | +83.4% |
| **8.0%** | **17.5x** | **0.0%** | | | | |

**为什么市场长期交易在约 16x P/E？** `[M11 p.33]`：把"中位数"S&P 500 公司跑一遍 **30 年 DCF**（4–5% 收入增长、温和的利润率扩张、8% WACC）⇒ DCF 价值隐含 **下一年 16.5x P/E**。模型输出：Discounted FCF $1,654,107；TV $439,427；NPV $2,093,535；TV multiple 10.0x；WACC 8.0%；EV $2,093,535；Net Debt $732,737；Market Cap $1,360,797；shares 150,000；**Price $9.07；EPS $0.55；P/E 16.5x**。

**WACC 锚** `[M11 p.34]`：
> "The median market P/E of 16x approximately corresponds to an 8% WACC."（市场 16x 的中位 P/E 大致对应 8% 的 WACC。）

方法：先把基线 WACC 调整为市场 WACC，再按风险水平调整基线 WACC（是医疗器械公司还是生物科技？）。

**WACC 不可靠的五个理由（FIVE REASONS WACC IS WHACK）** `[M11 p.35]`：

| # | 理由 | 说明 |
|---|---|---|
| 1 | **单因子模型** | Beta——CAPM 暗示更高波动的名字应带来更高回报。真的吗？不是（见 "betting against beta"） |
| 2 | **CAPM 试图把 Ke 变成一个 YTM 等价物** | 但股权的现金流**不是合约化的** |
| 3 | **用哪个无风险利率？** | 口径本身不明确 |
| 4 | **用哪个 ERP？** | **5% 只是"市场永远应该交易在 16x"的反向说法，不实用** |
| 5 | **100–200bps 的 WACC 差异意味着截然不同的结果** | **虚假精度（false precision）** |

**学术 vs 现实** `[M11 p.37]`：
- EMH：市场准确折现所有公开信息，因此被正确定价；CAPM 描述风险（beta）与回报的关系；用恒定 5% ERP，因为那是观察到的长期均值。
- 现实：真实 ERP 随流动性、风险前景与情绪波动；CAPM 只用 beta 决定权益成本（过度简化）；WACC 依赖过度简化的权益成本和被扭曲/不可知的无风险利率；**"市场永远不可能像学者希望的那样有效，因为股票反映的是集体对 30+ 年 FCF 的看法。"**
- **"WACC 与 CAPM 只是学术框架，不是市场法则。"**
- **"精确度很重要：6% WACC（25x P/E）到 12% WACC（8x P/E）是巨大的差别！"**
- **"尽管有这些局限，DCF/WACC 与倍数（DCF 的速记）仍是我们拥有的最好工具。"**

**真正驱动市场的东西** `[M11 p.38]`：恐惧 vs 贪婪；不确定性 vs 可见度；流动性（或缺乏流动性）；混乱 vs 平静。

**股市回报** `[M11 p.39–42]`：1915 年以来**均值 8.7%、中位数 11.4%、最大 +81.5%（1915）、最小 (47.1%)（1931）、标准差 20.3%**。1 个标准差（68% 的时间）⇒ 大概率回报 **-12% 到 29%**。分十年：1920s 127%、1930s (42%)、1940s 34%、1950s 257%、1960s 54%、1970s 17%、1980s 227%、1990s 316%、2000s (24%)、2010s 199%。

**学术方法的局限** `[M11 p.43]`：如果别人用同样的解释性框架，反身性会放大影响；实践局限（对 FCF 流的可见度；折现率的问题）；"完美价格"的幻觉需要 (1) 对几十年 FCF 的完美可见度，以及 (2) 真正准确的折现率（后者是群体偏好的函数，会变）。

### 1.5 专业实践调查：估值方法在实务中怎么用（Equity Valuation: A Survey of Professional Practice）

**调查设计** `[Survey p.3–4]`：目标是提供一份**中立**的当前股权估值实务快照；问卷设计刻意允许所有估值方法，并明确给出 24 个模型选项，使结果可比。**CFA Institute 赞助**（问卷更长更全面）；在专业股票分析师中做**分层随机抽样**；有效回答 **近 2,000 份**（远超前人调查）。受访者来自美洲、亚太、EMEA 三大区域。

**表 1：估值方法的全球排序**（N = 1,980）`[Survey p.5]`：

| 方法 | 使用该方法的受访者占比 | 条件频率（在该方法的使用者中，用于多大比例的估值案例） |
|---|---|---|
| **市场倍数法（market multiples）** | **92.8%** | **68.6%** |
| 现值折现法（present discounted value） | 78.8% | 59.5% |
| 资产基础法（asset-based） | 61.4% | 36.8% |
| 实物期权法（real options） | **5.0%** | 20.7% |
| 其他 | 12.7% | 58.1% |

- **"条件频率" > 50% ⇒ 通用工具；< 50% ⇒ 专门工具。** `[Survey p.5]`
- **实际应用频率 = 受访者占比 × 条件频率**：市场倍数 **64%（0.928 × 0.686）**、现值折现 **47%**、资产基础 **约 23%**、实物期权 **约 1%**。`[Survey p.5]`
- ⇒ **倍数法与现值折现法是两大通用工具；实物期权法虽被大量著述，却极少被使用。** `[Survey p.5]`
- "Other approach" 里按频次：技术分析与动量、（自有）量化模型/分析（各 15–20 次提及）；LBO 分析；（先例）交易倍数与并购可比；分部加总（SOTP）；多因子模型；FCF yield；HOLT CFROI。`[Survey p.5]`

**表 2：市场倍数法的全球证据**（N = 1,765）`[Survey p.5]`：

| 倍数 | 受访者占比 | 条件频率 |
|---|---|---|
| **P/E** | **88.1%** | **67.2%** |
| **EV 倍数**（EV/EBITDA、EV/经营利润等） | **76.7%** | **61.1%** |
| P/B（市净率、市净率调整后） | 59.0% | 44.8% |
| P/CF（对某种现金流口径） | 57.2% | 54.6% |
| P/S（市销率） | 40.3% | 45.7% |
| D/P（股息率）/ P/D | 35.5% | 44.3% |
| 其他比率 | 11.6% | 58.5% |

- **P/E 的统治地位**：Graham & Dodd（1934, p.351）把 P/E 定为当时的标准方法；Block（1999）调查中 P/E 已居首；本次调查确认其持续 primacy——**0.928 × 0.881 = 81.8% 的全部受访者在估值工作中使用 P/E**。`[Survey p.6]`
- **EV 倍数被严重低估**："使用市场倍数法的分析师中超过四分之三使用 EV 倍数"——**0.928 × 0.767 = 71.2%** 的受访者有时使用企业倍数；**EV 倍数在此前调查中被普遍忽略**。`[Survey p.6]`
- "Other ratios" 中最常见的自填项是 **PEG 比率**（P/E ÷ 增长率）。`[Survey p.6]`

**表 3：P/E 分母的盈利口径**（N = 1,505）`[Survey p.6]`：

| 口径 | 受访者占比 |
|---|---|
| **预测净利（forward/leading net income）** | **61.1%** |
| 预测经营利润 | 20.1% |
| 追溯净利（trailing net income） | **8.8%** |
| 追溯经营利润 | 4.5% |
| 其他 | 5.5% |

- ⇒ **前瞻 P/E 远优于追溯 P/E；净利口径远优于经营利润口径。** `[Survey p.6]`
- 区域差异 `[Survey p.10]`：美洲分析师更多用追溯经营利润、更多用预测经营利润；**亚太与 EMEA 更多用预测净利**；各地区追溯净利与追溯经营利润的使用率都很低。整体上"经营利润口径"在美洲的根基更深。

- **CAPM 是最常用的权益成本估计法（68%），且其用户在 78% 的必要报酬率估计场合使用它。** `[Survey p.7]`
- **24.5% 的分析师根本不估 ERP**——可能反映"公司统一规定的溢价"或"直接用金融数据商（如 Bloomberg）的溢价"。`[Survey p.8]`

**其他实务事实** `[Survey p.9]`：
- **三分之二的分析师报告：估值方法会随所估股票的行业/板块而变。**
- 使用外部数据商作为**估值输入**来源的比例 **41.6%**；但对**估值模型、目标价与评级**，数据商的使用率平均 **≤ 20%**。

**区域、职能、雇主、客户类型的显著差异** `[Survey p.10–11]`：
- **区域**：现值折现在**亚太与 EMEA 的根基显著强于美洲**；资产基础法在亚太用得比美洲多；**P/E 在所有地区都是第一**；EV 倍数在 EMEA 用得显著多于亚太；亚太与 EMEA 的 P/B 使用显著多于美洲；美洲的现金流比率与 P/S 显著高于亚太与 EMEA；亚太与 EMEA 的股息率使用显著多于美洲。
- **职能**：三类职能（买方分析师、卖方分析师、PM）的倍数法使用相近、其余方法的相对排序完全一致；**PM 用 DCF 频率更低、用 DDM 频率更高**；卖方分析师使用数据商约为总体均值的 **40%**，买方分析师约为均值，**PM 约为均值的 1.3–1.5 倍**。
- **雇主类型**：**对冲基金是最有差异的一群**——投资银行（**65.6%**）与对冲基金（**64.3%**）使用 EV 倍数显著多于投资管理公司（**55.8%**），投资银行显著多于券商（**57.8%**）；券商与投资银行用现值折现显著多于对冲基金；**实物期权法在投资管理公司最少、对冲基金最多**（差异显著）；**超过五分之一的对冲基金分析师选择"其他方法"，是其余三类雇主的两倍**；**对冲基金用资产基础法多于现值折现法**。
- **客户类型**：面向私人客户的分析师用现值折现少于面向机构客户者；在 DCF 内部，私人客户更偏好股利折现模型。

**结论** `[Survey p.11–12]`：**无论区域、职能、雇主类型还是客户类型，市场倍数法与自由现金流模型都是占主导地位的估值模型类别。** 显著差异须有合理的经济解释。

> **对本技能的用法**：这份调查给出"专业实务用什么方法"的经验基线——**倍数法（92.8%）压倒 DCF（78.8%），而 P/E（88.1%）与 EV 倍数（76.7%）是倍数法的两大支柱；前瞻盈利（61.1%）是 P/E 的默认分母**。课件 Module 11 用"市场基准"（S&P 500 NTM P/E 22 年中位数 15.9x、市场隐含 WACC 8% ⇒ 16x–16.5x P/E、市场增长 5–6% 收入 / 9–12% EPS、历史 6%）`[M11 p.31–34]` 给出"市场在用什么倍数"的基线，两者互相印证：**倍数法既是实务主流，也是市场共识的表达方式，因此对倍数法的任何偏离都必须有明确的差异化理由。**

### 1.6 终值方法的选择：永续增长 vs 退出倍数

| 方法 | 课件用法 | 何时适用 | 风险 |
|---|---|---|---|
| **永续增长率（perpetuity growth）** | 基线模型 **2.5%** `[M11 p.22]` | 商业进入稳态、增长可收敛到宏观名义增速时 | **50–100bps 变化即"决定生死"** `[M11 p.24]`；概念上极难（长期增长率、企业失败率、增长阶段、周期性）`[M11 p.23]` |
| **退出倍数（exit multiple）** | 基线模型隐含 **18.6x** `[M11 p.22]`；反向 DCF 用 **10.0x ex-growth multiple** `[M11 p.48]` | 当终值倍数可由可比/历史锚定时；**终值占比过高时用它把价值"拉回"** | 倍数本身隐含对长期增长与质量的判断；同样不精确 |
| **两者并用（推荐做法）** | 30 年分段递减 FCF + ex-growth 终值倍数 `[M11 p.26, p.48]` | **课件推荐的默认**：把主要价值推进 FCF 预测期 | 模型复杂；需分阶段假设 |
| **30 年 DCF 反向工程** | 60% 的价值在第 15 年及以后 `[M11 p.7]` | 长期成长股、远期价值占比高的股票 | "荒谬地不精确"，但比单一终值增长率更可推演 |

- **终值占比警示** `[M11 p.23]`：典型 5 年 DCF 中 **约 85%** 的价值在终值（基线模型 **84.3%**）。→ "3 年之后，TV 可能占 NPV 的 85%+，那为什么不直接用倍数？！" `[M11 p.53]`
- **反向 DCF 的终值纪律** `[M11 p.48]`：对终值施加 **ex-growth multiple**，**期望低于 NPV 的 25%**。
- **Mauboussin 的终值纪律** `[DCE p.3–4]`：**永续法下终值即使折现回现值，仍常占公司价值的 60–70%**；且**永续假设不排除增长**——增长与价值创造没有必然联系，**核心假设关乎增量价值创造，而非增量增长**。

### 1.7 DCF 模型的常见错误（Mauboussin《Common Errors in DCF Models》完整清单）

**判据**：DCF 模型应当**经济上可靠（economically sound）且透明（transparent）**。经济上可靠 = 公司的回报与增长模式与其行业地位、以及均值回归的充分实证记录一致；透明 = 你理解所选方法与假设的经济含义。**大多数 DCF 模型通不过这两条检验。** `[DCE p.2]`

**为什么 DCF 是对的标准**：股权投资者是生意买家。判断一笔生意的价值取决于它产生的现金流——**没有可分配现金就没有价值；现金要付饭钱和房贷，盈利不行。** 债券与商业地产市场的估值全是关于现金的，但实践中很少有股票投资者纠结现金，**盈利与倍数这类价值代理主导了华尔街的估值工作**。结果是自满与虚假的理解感；于是多数投资者不做基本面估值，真做了也常常做错。`[DCE p.1–2]`

**凯恩斯的话**："I'd rather be vaguely right than precisely wrong." `[DCE p.2]`

**八个最常见错误** `[DCE p.2–8]`：

| # | 错误 | 要点 | 出处 |
|---|---|---|---|
| 1 | **预测期太短（Forecast horizon too short）** | 批评"两年以外的预测都可疑"是**没有道理的**：理解一家生意的吸引力需要知道价格代表的那一组财务预期；**市场历史上交易在 P/E 的中双位数至高位**，今天的股价反映了**许多年后**创造价值的盈利与现金流预期（就像餐饮业高管选新址不会只看两年盈利）。**但预测期太短会迫使建模者把价值倾倒进终值（"value dump"），产生完全不经济的持续价值**，令预测期与终值估计**双双失去用处**。**建议：显式预测期不少于 5 年**；许多公司需要**超过 10 年**；**理想情况下显式预测期应捕捉至少三分之一的公司价值**，并对预测财务表现有清晰假设 | DCE p.2–3 |
| 2 | **不经济的持续价值（Uneconomic continuing value）** | 必须记住微观经济学最有力的教训之一：**竞争力量会确保 ROI 随时间趋近资本成本**。合理结构是：**显式预测期捕捉新投资的超额回报（价值创造），终值反映公司耗尽增量价值创造机会之后的价值**。卖方模型样本中预测期**通常 5 年或更短** ⇒ 价值负担被堆在终值上 ⇒ 模型无法反映公司价值创造的模式与时点。**典型恶习：把倍数施加在期末 EBITDA 上估终值，而该倍数很少有扎实的经济基础，多数分析师不知道它隐含什么财务表现。** 极端例子：在某些假设下 **13.0x EBITDA 倍数隐含永续 6% 的盈利增长与 150% 的增量资本回报——人类历史上没有任何公司做到过**。**高比例的价值被归给终值，几乎总是反映预测期不当。** 正解是"价值创造期 + 价值中性期"分段：用永续假设资本化最后一年的 NOPAT（按资本成本折现），**即使折现回现值，这个终值常常仍占公司价值的 60–70%**；且永续假设**不排除增长**——**核心假设关乎增量价值创造，而非增量增长** | DCE p.3–4 |
| 3 | **资本成本（Cost of capital）** | 资本成本是投资者持有资产所要求的回报率，即**机会成本**，也是折现未来现金流的恰当比率。**债务成本透明**（合约化付息与还本，信用状况决定溢价，大型流动性公司债市场使比较相对直接）；**权益成本是隐含的、更难估计**（高于债务成本因权益求偿权次级），**没有简单的估计方法**。CAPM 是最常用方法（Ke = Rf + Beta × ERP），但 **beta 理论上漂亮、实践与实证上失败**：理想上我们要前瞻 beta（无法可靠估计），实证上 beta 对回报的解释力很差——**2006 年 3 月中旬通用汽车 beta 为 1.3，而雅虎 beta 超过 1.6**；很难说雅虎在合适的预测期内比通用汽车显著更危险，隐含期权波动率反而显示 GM 风险更高。**ERP 的问题**：理想上是前瞻估计，多数人依赖历史值；**几何平均 ERP 为 1982–2005 的 1.9 个百分点、1962–2005 的 3.7 个百分点、1926–2005 的 6.2 个百分点**（算术平均更高）；**偏好长期模型用几何平均、短期回报预测用算术平均**；且 ERP 很可能**非平稳**（过去的股价回报、股价波动率、商业状况都在变）⇒ 用历史均值可能极具误导。**在 2006 年 3 月中旬 4.7% 的无风险利率上加 200 还是 600 个基点，会显著改变模型输出**；**部分学者认为 ERP 在 3–4 个百分点区间较为合理，其中点隐含市场长期回报约 8%**。**最佳建议：选定一个在商业与经济意义上说得通的资本成本。** 最后：**与其围绕资本成本做敏感性分析，不如对关键经营价值驱动因子（销售增长、利润率、资本密集度）设定替代情景**——历史上伟大的投资者靠更好地理解价值驱动因子而非更好的资本成本判断来创造边缘 | DCE p.4–6 |
| 4 | **假设的投资与盈利增长不匹配（Mismatch between assumed investment and earnings growth）** | 公司要长期增长就必须投资（营运资本、资本开支、并购、研发），**ROI 决定公司把投资转化为盈利增长的效率**。**DCF 模型普遍低估了实现所假设增长率所必需的投资**，两个来源：① 分析师看到公司过去高度并购化，就外推一个"并购增强"的增长率，却只反映当前业务的资本开支与营运资本需求（**可通过仔细考虑来自现有业务的增长来缓解——它会低于并购驱动的比率**）；② **分析师经常脱离投资独立地预测增长（销售与利润率）**。**简单的检查方法：在模型里加一行 ROI；如果看到 ROI 在没有战略性理由的情况下大幅上升或下降，模型很可能不可靠。绝大多数模型根本没有努力体现增长与投资之间的联系。** | DCE p.6 |
| 5 | **其他负债处理不当（Improper reflection of other liabilities）** | 在 FCFF 框架下，先用未来现金流的现值确定企业价值，再**加上现金与其他非经营性资产、减去债务与其他负债**得到股东价值。多数负债（债务、许多养老金计划）相对容易确定；**另一些负债（员工股票期权等）则更难捕捉，而大多数分析师在经济可靠的意义上做得很差**。其他负债通常只对少数几家公司重要（退休后福利集中在制造业如汽车，员工股票期权最常见于知识与服务行业如科技、金融服务）。**员工期权是典型短板的例证**：多数 DCF 模型仅通过完全稀释股数反映历史期权授予——**完全稀释股数只反映价内期权，对负债规模捕捉得极差**；**会计准则虽已要求费用化期权，很少有 DCF 模型明确把未来期权授予当作费用处理**；分析师模型常显示流通股数上升（稀释），有时纳入期权收入却**不反映任何稀释**。**正解：把已授予期权当作或有负债处理，使用基本股数，并把未来期权授予作为费用反映** | DCE p.6–7 |
| 6 | **折价到私募市场价值（Discount to private market value）** | 仍是 1980–90 年代投行心态的**不幸遗留**：DCF 算出一个价值后，再打上 **20–25% 的"公开市场折价"**，在电信业最常见。**这通不过透明性检验**：应反过来问——为什么私募（战略或财务）买家会愿意为公开市场价值付溢价？也许买家认为股票被低估（那溢价就抹掉了好处）；更可能是买家相信自己能从被收购资产产生比标的公司自身更高的现金流。**协同效应（synergies）往往足以justify 全部或大部分溢价**；或者买家能重新配置资本、或用财务杠杆提升税后现金流。**要合理，一个反映公开市场折价的 DCF 模型必须已经纳入协同效应或某种公司自身无法实现的更高现金流的催化剂。** 建模可能的交易协同是允许的，**但该练习应与对独立业务的估值分开**——折价到私募价值模型**把基准现金流与协同现金流混为一谈，透明性不足** | DCE p.7 |
| 7 | **重复计算（Double counting）** | 模型不应把一美元的价值（或负债）计算超过一次，而 DCF 模型常常无意中重复计算同一价值来源。**典型例子是股票回购**：现金流强劲的公司往往有持续回购的记录，分析师识别出回购倾向与强现金流后，就在模型里假设公司用 FCF 缩减股数——**这重复计算了，因为模型给现金流估了值（一次），又用同一现金流减少股数（两次）**；而且这个错误回避了"判断未来股价"这一真正的分析难题（判断公司可能买回多少股票的唯一正当方法）。**另一个较少见的例子：把利息收入计入现金流计算、同时把现金余额加进企业价值**；或**从现金流中扣除融资成本、同时从企业价值中扣除债务** | DCE p.7 |
| 8 | **情景（Scenarios）** | 对 DCF 最常被引用的批评是"假设的小幅变动导致价值的大幅变化"——这部分已由**延长预测期**缓解。**但更进一步：所见报告中的绝大多数只提供一个 DCF 情景，而分析师常把目标价钉在那个情景上。投资本质上是概率性的，一个情景——往往还建立在 shaky 假设上——不构成周密分析。明智的投资者需要考虑多个情景。** 虽然许多模型确实做了敏感性分析（通常是资本成本、增长或终值假设驱动的网格），**但这些网格对想理解业务前景的人几乎不提供相关信息**；投资者应转向价值驱动因子——**销售、利润率、投资需求**——作为差异化认知的来源。**即便基于价值驱动因子的敏感性分析通常也是错的，因为它没有考虑价值驱动因子之间的交互作用**；**Proper scenario analysis 要考虑销售、成本、投资的变化如何导致价值驱动因子的不同结果**。**情景分析同时处理不确定未来：通过"如果…那么…"情景、并坚持对期望值做适当折现（或安全边际），投资者可以安全而审慎地权衡各种结果** | DCE p.7–8 |

**结论（Mauboussin）** `[DCE p.8]`：理论与实践都告诉我们，公司的价值是未来现金流的现值。投资者主要是在**以低于其价值的价格买入现金流，或以高于其价值的价格卖出**。因此投资者必须能**智能地建模现金流并识别差异化认知（variant perception）——一个有根据的信念，即市场对公司给出了错误的估值**。**商学院学生在课堂上学 DCF，但用到真实世界时，投资者必须确保模型经济上可靠且透明；实践中极少有模型通过这两项检验。**

**"增长不等于价值"的证明（附录 A）** `[DCE p.9–10]`：

```
Value = NOPAT_(CAP+1) × (1 − growth/ROIIC) / (WACC − g)
其中：NOPAT = 税后净经营利润；growth = NOPAT 增长率；ROIIC = 增量投资回报率；WACC = 加权平均资本成本
```

- 算例：NOPAT $100、growth **5%**、ROIIC **12%**、WACC **9%** ⇒ Value = 100 × (1 − 5%/12%) / (9% − 5%) = **58.33 / 4% = 1,458.3**。
- 换成 FCF 永续法：因 FCF = NOPAT − 投资，且 12% × 投资 = ΔNOPAT = 5 ⇒ 投资 = 5/12% = 41.67 ⇒ FCF = 100 − 41.67 = 58.33 ⇒ Value = 58.33 / 4% = **1,458.3**。**两者答案完全相同（假设一致时）。**
- **当 ROIIC = WACC 时（增量回报等于资本成本，即增量投资的净现值为零），两种公式都坍缩为永续假设。** `[DCE p.10]`

### 1.8 课件视角的 DCF 错误清单（10 条）

课件把错误归到两类：**"garbage in, garbage out"** 的结构性不精确 `[M11 p.20–21]`，以及**具体建模错误**：

| # | 错误 | 为什么错 | 出处 |
|---|---|---|---|
| 1 | **用 5 年 DCF + 单一终值增长率** | **约 85% 的价值坐在终值里**；终值增长率概念上极难（长期增长、企业失败率、增长阶段、周期性），**50–100bps 决定生死**。应改用 **30 年 DCF + 分段递减 + ex-growth 终值倍数** | M11 p.23–26 |
| 2 | **把 WACC 当成精确值** | 五个不可靠理由：单因子 beta；CAPM 把股权现金流当合约化（不是）；无风险利率口径不明；**5% ERP 是循环论证**；**100–200bps ⇒ 截然不同结果** | M11 p.35 |
| 3 | **忽略终值感知风险（TV perception risk）** | 同一家公司在 **25x** 与 **10x** 处隐含了截然不同的终值——这是 META 的教训 | M11 p.149 |
| 4 | **轻率地施加倍数** | "Don't apply multiples lightly!"；**20x 倍数隐含"增长 + 持续数十年"** | M11 p.51, p.107 |
| 5 | **有杠杆/无杠杆口径错配** | **EV/Net Income、P/EBITDA、L-FCF/EBITDA 都是错误的**。**"Match unlevered to unlevered. Match levered to levered."** | M11 p.78 |
| 6 | **忘记扣净债务/非股权索取权** | 优先股、合资、租赁会计，**以及诉讼负债常常要从 EV 中扣除** | M11 p.79 |
| 7 | **对峰值/谷值利润率施加倍数** | 必须先正常化：收入（中周期）、利润率（不是峰也不是谷）、资本结构（偿债/再融资）、资本密集度（折旧 vs capex） | M11 p.97, p.104 |
| 8 | **使用远高于 25x 的正常化倍数** | 成熟资产很少持续高于 25x；**通常用 12–20x** | M11 p.108 |
| 9 | **把内在价值当法律而非感知** | 框架影响行为，但感知可以差异极大 | M11 p.8 |
| 10 | **不分解回报来源** | 必须区分 EPS 增长 / P/E 扩张 / 修正；**P/E 扩张是最短暂的一项** | M11 p.135–137, p.128 |

### 1.9 倍数家族：主框架

**THE PRIMARY VALUATION FRAMEWORK: MULTIPLES** `[M11 p.47–48]`——由于 DCF 的结构性不精确，倍数是最常被实践的估值方法。路径：**预测基本面 → 施加一个倍数**。

**估值方法与使用场景** `[M11 p.49, p.75]`——"下面哪种估值方法最好？答案：取决于……"

| 方法 | 定义 | 使用场景 |
|---|---|---|
| P/E | 当前每股净利的倍数 | 通用 |
| DCF | 无杠杆 FCF 折现值，扣净债务，除以股数 | 通用 |
| Takeout value（收购价值） | 公司在收购交易中的每股价值 | 收购是潜在结果时 |
| FCF yield | 目标 FCF 收益率的函数 | 通用 |
| EV/EBITDA | EBITDA 的倍数，扣净债务，除以股数 | 通用 |
| EV/Sales | 销售额的倍数，扣净债务，除以股数 | **尚不盈利的公司** |
| Normalized EPS（正常化 EPS） | 正常化盈利能力的倍数 | **当前盈利被高估或被压低时** |
| Dividend yield | 目标股息率的函数 | 分红股、股息导向投资者 |
| EV/GP（毛利倍数） | 毛利的倍数，扣净债务，除以股数 | **可自由支配 opex 暂时偏高时** |

**核心公式** `[M11 p.50]`：
```
P/E   × EPS   = PRICE      →  什么 P/E？什么 EPS？何时的价格？
NTM P/E  × NTM EPS  = PRICE
NTM2 P/E × NTM2 EPS = PRICE（12 个月后）
```

**倍数是什么？** `[M11 p.51]`——施加倍数就是"资本化"，它透露了你对预测指标的看法：
> **"If I apply 10x to a figure, I'm roughly saying 'this metric is not going to grow, but will stick around for about 25-35 years'."**
> **"If I apply 15x to a figure, I'm roughly saying 'this metric is going to grow about 5%, and will stick around for 25-35 years'."**

这就是为什么理解**可持续性、耐久性、正常化**在施加倍数时至关重要。

**为什么用倍数？（推导）** `[M11 p.53–55]`：DCF 可以写成"第 1 年 FCF 的倍数"作为速记，但现金有机会成本、现金流有风险，所以必须折现。$100 买价 / $10 年 FCF 共 10 年 = **10.0x**（回收期 10 年）。在 **10% 折现率**下，同一现金流只值 $61 ⇒ **6.1x 倍数**。加上终值（第 10 年 10x）⇒ 回到 **10.0x**；**即使预测了 10 年 FCF，终值仍约占总价值的 40%**。

**为什么投资者用倍数？** `[M11 p.63]`：
- 一般怀疑 DCF（"garbage in, garbage out"），除非在极端情形；改一改增长或 WACC 就极易被操纵；难以与同业和历史对标；**终值往往占 DCF 的 85%+，本身就是一个倍数**。
- **简洁方法**：易于实施；易于对标；可与该资产的历史交易区间比较；可与同类资产比较。

### 1.10 P/E：E 才是关键

**"Generally, it is the E in the P/E that will matter much more!"** `[M11 p.62]`
- **"P/E 报价通常用一致预期，但 P/E 里的 'E' 才是关键。"** `[M10 p.79]`
- **前瞻 vs 追溯（forward vs trailing）**：P/E 分为 **LTM P/E**（追溯）与 **NTM / NTM2 P/E**（前瞻）。核心公式 `[M11 p.50]` 明确区分 **NTM EPS**（未来 12 个月）与 **NTM2 EPS**（再往后 12 个月，即前瞻季度 5+6+7+8）。NTM P/E 图表同时构建**绝对**（坐标轴 10x–35x）与**市场相对**（该股 NTM P/E − S&P 500 NTM P/E，坐标轴 −5x 到 +18x）两条线——**"看市场相对倍数以调整 prevailing 市场水平"** `[M11 p.69–70]`。
- **GAAP vs 非 GAAP、盈利的三种成分（Rappaport & Mauboussin）** `[MB-PE p.8–9, p.13]`：
  - **"big-bath accounting"（大洗澡会计）**：数十亿美元的重组费用是"会计匹配概念严重走偏"的典型例子——这些"一次性"费用涵盖关闭设施、整合被收购公司、支付裁员补偿、精简运营等异常与非经常事件；**这类费用出现的频率给"一次性"这个词赋予了全新含义。**
  - **不批判性接受已报告盈利之所以更危险，是因为盈利数字排除了什么**：现行会计规则要求公司在**报表附注**中披露员工股票期权的成本，但**并不要求把该成本计入盈利**；**该成本可能相当可观，对高科技初创公司尤其如此。**
  - **旧经济 vs 知识经济**：所谓"旧经济"公司把大部分投资资本化（以直线法或加速法在估计使用年限内摊销固定资产），**而知识公司把大部分投资费用化**；这一转向影响盈利及其他会计比率，**但对股东价值计算没有影响**——就股东价值而言，**$1m 投入费用化的知识与 $1m 投入可折旧的有形资产被同等对待**；决定价值的是**已花掉这 $1m** 以及**该投资产生的估计现金流**。
  - **盈利的三分类**（Revsine, Collins & Johnson）`[MB-PE p.13]`：**永久性盈利（permanent）**——来自持续经营的利润（不含特殊或非经常项目），因通常被视为可持续而具价值相关性；**过渡性盈利（transitory）**——预计不会持续，如终止经营损益、异常损益，**对价值没有持续影响**；**价值无关盈利（value-irrelevant）**——源于会计政策变更、**没有未来现金流后果**。
  - **"大多数分析师在 P/E 计算中只纳入永久性盈利"**，但 First Call 研究总监指出：**"什么算非经常或非经营，完全取决于观察者的眼睛。"** ⇒ **我们面对的不仅是被随意计算的盈利，还有被随意挑选的盈利成分来充当 P/E 的分母。**
  - **"P/E 不决定价值，它是导出价值。P/E 分析不是一个分析捷径，它是一条经济学死胡同。"** `[MB-PE p.13]` 在盈利的局限之下，**没有任何盈利数字能救活一个经济上贫血的 P/E 倍数。**
  - **PEG 同样站不住脚**：PEG 的分子就是 P/E 本身；**在 P/E 与任意短期的盈利增长预测之间，看不到经济上可靠的关联**。极端的无增长案例：每股永续 $10 盈利、**10% 资本成本**、无通胀 ⇒ **股价 $100，即 P/E = 10**。`[MB-PE p.13–14]`

- **"长进倍数"（Grow into the multiple）** `[M11 p.60–61]`：FY5 P/E —— Stock 1（起始 10.0x，EPS −5%/年）→ 12.9x；Stock 2（起始 30.0x，EPS +15%/年）→ 14.9x；Stock 3（起始 100.0x，EPS +70/60/50/40/30%）→ 13.5x ⇒ **Stock 2 与 3 已经"长进"了更具吸引力的倍数**。快速增长 EPS 流在第 0–1 年看起来贵，在第 3–6 年常常便宜。Fast Grower 算例：$10.00 / EPS $0.10 = 100.0x，逐年滚动 P/E 40.0x（第 1 年）、20.0x（第 2 年）、13.3x（第 3 年）、10.0x（第 4 年）、6.7x（第 5 年）、5.0x（第 6 年）。
- **TSLA 案例** `[M11 p.62]`：Street 当时 $37.0 价 / $0.01 EPS = **3700.0x P/E** → Street 现在 $1.50 / 24.7x → 实际 $12.47 / 3.0x ⇒ **30 倍股**。
- **一次性盈利被资本化（temporary tailwind shorts）** `[M11 p.52]`：EPS 每年基线 $1.00 + 第 2 年一次性 $1.00；市场平时付 **25.0x**，第 2 年付 **35.0x** ⇒ 价格 $25.00 → $70.00 → $25.00；**同比 +180.0%，随后 (64.3%)**。
- **P/E roll-forward** `[M11 p.64]`：投资就是价格预测；P/E roll-forward 必须预测 (1) EPS 与 (2) P/E 的变化。算例：现在 $20.00 / $1.00 / 20.0x → 1 年后 $30.00 / $1.20 (+20%) / 25.0x (+25%) ⇒ **+50.0% 股价变动**。
- **再定价（Re-rating）** `[M11 p.65]`：
  > "The voodoo of it is figuring out the multiple. **80% of a stock's move is the multiple.** That is the hardest part. You can get the numbers right and the stock moves the wrong way."
- **P/E 周期法** `[M11 p.138]`：过去 5 年 SBUX 在 **18–36x** P/E 区间交易（"再告诉我一次市场有多有效？"）。规则：**在 P/E 区间低端买入，在高端减仓**（更偏战术）。例："在 **22x 以下 NTM P/E 买入 SBUX**" ⇒ 会在 2018/5 的 $210 与 2020/3 的 $195 产生买入（当前 $315）。
- **回报分解** `[M11 p.135–137]`：DPZ 2008 $13 / EPS $0.97 / 13.0x → 2022 $329 / $13.86 / 23.7x ⇒ **总回报 +2,500%**，其中 **EPS +1,325%**、**P/E +82%**。
  > **"RULE OF THUMB: P/E EXPANSION IS MORE EPHEMERAL THAN DURABLE EPS GROWTH."**
- **案例** `[M11 p.139–144]`：
  - **好公司、坏股票 —— MSFT**：1999 Revenue $19,747 / EPS $0.70 / Avg P/E 58.3x / 年末股价 $58.75 → 2016 Revenue $92,071（4.7x）/ EPS $2.79（4.0x）/ Avg P/E 18.8x（0.3x）/ 年末股价 $62.99 ⇒ **总回报仅 7.2%**。
  - **价值陷阱 —— BBBY**：EPS 曾见顶约 $5.07 后跌至 ($1.08)，股价归 $0.00。

### 1.11 有杠杆 vs 无杠杆（levered / unlevered）与 EV 桥

**Modigliani & Miller** `[M11 p.76–78]`：企业价值不取决于资本结构的选择——方向上正确，但会导致**高杠杆企业的 P/E 相对无杠杆企业出现实质性折价**。

算例：Biz A / Biz B 均 Revenue $100、EBITDA $10、10.0x 倍数 ⇒ EV 各 $100；Biz A Debt $0 ⇒ 市值 $100、股价 $10.00；Biz B Debt $50 ⇒ 市值 $50、股价 $5.00。在 D&A $2.0、Biz B 利息 $2.5 的条件下：Biz A 净利 $6.0、EPS $0.60、**隐含 P/E 16.7x**；Biz B 净利 $4.1、EPS $0.41、**隐含 P/E 12.1x**。

**你必须知道的分类** `[M11 p.78]`：

| 类别 | 指标 | 说明 |
|---|---|---|
| **无杠杆（UNLEVERED）** | EV/Sales、EV/EBITDA、unlevered FCF | 债务与股权都有索取权，或位于利息费用之前 |
| **有杠杆（LEVERED）** | P/E、levered FCF | 已偿付债务索取权，或已扣除利息费用 |
| **错误指标（INCORRECT）** | **EV/Net Income；P/EBITDA；L-FCF/EBITDA** | 口径错配 |

> **"Match unlevered to unlevered. Match levered to levered."**

**给企业估值（EV → 股权价值桥）** `[M11 p.79]`：从企业价值中扣除**非股权索取权**——主要是**净债务**；还要考虑优先股、合资企业、租赁会计；**诉讼负债常常也要从 EV 中扣除**。
算例：EBITDA $100 × 10.0x = EV $1,000；less Net Debt $250 = 市值 $750；÷ 10 稀释股 = **每股 $75**。

### 1.12 各类倍数详解与失效场景

**EV/Revenue** `[M11 p.80–85]`
- 使用场景：**公司尚未盈利**。TSLA：多头在 **2x EV/Revenue** 时正确地把 TSLA 视为便宜货。
- **选择 EV/Revenue 的关键**：倍数内嵌了对 (1) 增长、(2) 利润率结构的假设。**3x revenue at maturity 隐含约 20% 的经营利润率；6x revenue at maturity 隐含约 40% 的经营利润率。** "选 EV/revenue 倍数时，利润率结构是关键。"
- 生物科技速算：**5x peak revenue，折回贴现** `[M11 p.84]`。
- **正确的 EV/Revenue 倍数** `[M11 p.85]`：**一个 50% 正常化利润率的生意可以交易在 10–15x EV/Rev（对应 20–30x EV/EBITDA）；一个 5% 正常化利润率的生意可能只值 1–2x（对应 20–30x EV/EBITDA）。** 增长越快、正常化利润率越高，正确的 EV/Revenue 越高。
- AMZN 轨迹：EV/Sales **6.9x（2017A）→ 1.5x（2026E）**；EV/EBITDA **99.2x（2018A）→ 13.6x（2026E）**；P/E **2,364.1x（2018A）→ 18.4x（2026E）**。

**EV/GP（毛利倍数）** `[M11 p.86]`：用于调整**可自由支配 opex**。Company A 在 EV/EBITDA 上"看起来"更贵（10x vs 5x），但若 $20m opex 中有 $10m 是可自由支配的"增长 opex"，它可以砍掉 opex、扩张盈利能力，**并以与 B 相同的 EV/EBITDA 交易**。（两者：EV $100、Revenue $50、GP $25 且毛利率 50%、EV/Revenue 2.0x、EV/GP 4.0x；opex ($20) vs ($10) ⇒ EBIT $5 vs $15、D&A $5、EBITDA $10 vs $20 ⇒ **EV/EBITDA 10.0x vs 5.0x**。）

**EV/EBITDA** `[M11 p.87]`：当 **EBITDA 盈利但几乎没有 EPS**（常因折旧很高）时使用——医院、酒店类公司常见。通常被视为 **P/E 之后最受欢迎的次级估值倍数**；也常被用作**收购倍数**。

**FCF yield（自由现金流收益率）** `[M11 p.88]`：倍数的倒数。**FCF / 市值 = FCF yield；市值 / FCF = FCF 倍数。**
- 有杠杆口径：**Levered FCF yield = L-FCF / MCAP**；无杠杆口径：**Unlevered FCF yield = UL-FCF / EV**。
- 许多投资者偏好它，因为**现金驱动价值（而非会计 EPS）**——"EPS 本来就是 FCF 的代理，为什么不直接用 FCF？" 也用作**股息率的心理代理**（"如果公司把全部 FCF 都发成股息，收益率会是 x%"）与**回收期代理**（"10% 的 FCF yield 意味着在零增长下 10 年可以买回整个市值"）。
- 算例：EV $500；Net Debt $100；市值 $400；FCF $40 ⇒ **FCF Yield, Levered 10.0%**。

**驱动倍数的因素** `[M11 p.92]`：市场倍数；增长；正常化盈利能力；资本密集度；久期/质量/终值可见度。
**再定价的驱动** `[M11 p.93]`：对增长与质量的信念转移（Focus Five）；通常是事实格局的某种变化；信息被揭示；**"市场当面给了你一巴掌"**。
**模型与股价的联动** `[M11 p.94]`：NVDA NTM P/E vs 模型——Revenue $4,682→$9,714（**+107.5%**），Operating Profit $759→$3,616（**+376.4%**），margin 16.2%→37.2%，**Avg P/E 20.0x → 22.0x → 30.0x → 43.0x**（C2014–C2017）。
**施加倍数：先看基本面** `[M11 p.95]`："我们建模有很多原因，但最终模型是一个预测工具。" 框架：识别模型中对股价轨迹具**决定性**的驱动；聚焦把这些项目预测得比人群更准；先理解历史联动，再预测未来的联动。

**失效场景（when each breaks）**

| 倍数 | 失效场景 | 出处 |
|---|---|---|
| **P/E** | ① 收入超高增长的年轻公司；② 利润率为负的年轻公司；③ 有临时经营亏损的公司（COVID 冲击等）；④ 刚走出资本周期、折旧远高于 capex 的公司；⑤ 有新业务/新分部产生重大亏损的公司 → **这些情形用正常化盈利分析** | M11 p.97 |
| **P/E（盈利质量）** | ① **"big-bath accounting"** 让"永久性盈利"被侵蚀；② **员工股票期权的成本被排除在盈利之外**（只在附注披露），对高科技公司尤其重要；③ **一次性项目被资本化**（市场在一次性 EPS 上给 35x）；④ 追溯盈利 vs 前瞻盈利口径混用（实务上 **61.1% 用前瞻净利，追溯净利仅 8.8%**） | MB-PE p.8–9, p.13；Survey p.6 |
| **EV/EBITDA** | **三大固有缺陷**（Mauboussin）`[MB-EV p.4–6]`：① **没有对业务的投资需求做恰当 reckoning**——EBITDA **低估了业务的资本密集度**，因此**高估了在正常运营下可分配的现金**（营运资本变动与并购同样关键）；② **倍数不显式反映风险**——**经营杠杆（经营利润变动百分比 ÷ 销售变动百分比）是商业风险的合适度量**，高经营杠杆的生意对销售变化极度敏感；③ **税**——两家 EBITDA 与资本结构相同的公司可能支付差异很大的税率，因而其 EV/EBITDA 合理地不同。 | MB-EV p.5 |
| **EV/EBITDA（非 GAAP 调整）** | **EBITDA 不是 GAAP 科目**，直接算法基于 GAAP 数据，但"EBITDA 是非 GAAP 加总"这一事实**制造了大量灵活性并鼓励公司对定义随意发挥**。最常见的是 **adjusted EBITDA**：剔除重组费用、减值等非经常项，并**加入收购协同与预期成本节约**——**私募股权公司收购后做出的调整，在 2017 年平均把 EBITDA 抬高 13.7%（2016 年为 9.6%）**；**调整最大的行业包括医疗保健、游戏与科技**。市场上还流行各种变体：**EBITDAC / EBITDAO / EBITDAP / EBITDAR / EBITDARE / EBITDAS(B、C) / EBITDAX / "community-adjusted EBITDA"**（后者把营销、研发、管理费用这类基本经营成本也剔掉）。 | MB-EV p.4, p.17 |
| **EV/EBITDA（ Buffett/Munger/Klarman）** | **巴菲特（伯克希尔 2003 年股东会）**："Any management that doesn't regard depreciation as an expense is living in a dream world. But of course, they are encouraged to do that by investment bankers who talk to them about EBITDA."；**芒格**："如果你每次看到 'EBITDA' 这个词就把它替换成 'bullshit earnings'，那你就能理解任何用了 EBITDA 的演示。"；**Klarman（Baupost）**："把 100% 的折旧与摊销加回来得到 EBITDA，使它更没有意义。那些把 EBITDA 当现金流代理的人，要么忽略了资本开支，要么假设企业不需要资本开支——也许他们相信厂房设备不会磨损。" | MB-EV p.4–5 |
| **EV/Sales** | 公司已盈利时可能给出过高倍数；**必须配合利润率结构**（3x ⇒ ~20% op margin；6x ⇒ ~40%），否则倍数本身无意义。**实务中 EV/Revenue 的使用者只有 P/S 的约三分之一**（理论上它避免了 P/S 的分子分母口径错配） | M11 p.83–85；Survey p.6 |
| **EV/GP** | 当可自由支配 opex 不可削减时失效 | M11 p.86 |
| **所有 EV 类倍数** | **口径错配**（EV/Net Income、P/EBITDA、L-FCF/EBITDA）；**忘记扣净债务/优先股/合资/租赁/诉讼负债** | M11 p.78–79 |
| **周期性（cyclicals）** | 周期股用**峰值/谷值**盈利施加倍数会双向出错（peak on peak / trough on trough）；课件在 DCF 终值处特别点出**周期性**是终值增长率难以设定的原因之一。**更根本的解法是周期调整后的 P/E（CAPE）**——它用一整个经济周期的平均盈利作为分母，以消除单一周期位置的影响 | M11 p.23–26；M12 p.35–38；MB-PE p.20 |
| **租赁（leases）** | 租赁会计影响 EV 桥（须考虑租赁会计）；**租赁调整后的 EBITDA 变体是 EBITDAR**（加上租赁地产或飞机的成本），若原始 EV/EBITDA 未做租赁还原而对商用 EV/EBITDA，则**口径不可比**。**实务中还有专门为此设计的其他变体** | M11 p.79；MB-EV p.17 |
| **SBC 重的公司** | **员工股票期权的成本必须计入**。现行规则只要求**在附注披露**、**不要求计入盈利**；**完全稀释股数只反映价内期权，因此对负债规模捕捉极差**。**正确处理：把已授予期权当作或有负债、使用基本股数、把未来期权授予作为费用反映**——否则 EV/EBITDA 与 P/E 都会**系统性高估**（EBITDA 完全不加回 SBC 费用，而市值/股本已被稀释的规模低估） | MB-PE p.9；DCE p.6–7 |
| **金融股（financials）** | 课件 Module 11 **未给出银行/保险的专用倍数体系**（如 P/TBV、P/ROTCE）；**净债务/EBITDA 桥对金融股本身不适用**（利息是经营成本而非融资成本，EV 概念失真）。**补充线索**：实务调查里 **P/B 是第三常用的倍数（59.0%）**，在金融板块是主流；且**利息抵扣上限**（TCJA 后 ≤30% EBITDA/EBIT）**明确把金融服务业与房地产排除在受影响范围外**——这两类行业的 EV 桥与资本结构口径天然不同 | Survey p.5–6；MB-EV p.17 |
| **所有倍数的共同前提** | **"倍数不是估值，它是估值过程的速记"**；像大多数速记一样，**倍数自带盲点与偏见，而很少有投资者花时间与心思去理解它们**。以及 **"P/E 不决定价值，它是导出价值……它是一条经济学死胡同"** | DCE p.2；MB-PE p.13 |


### 1.13 选 P/E 的六条路径与倍数分析三维度 `[M11 p.66–67]`

**选 P/E？六条路径**：
1. **自身历史**（绝对 & 市场相对）
2. **同业**（"看起来像"）
3. **价值驱动因子**（DCF 情景）+ 外推
4. **反向 DCF 隐含 P/E**
5. **PEG / 算法法**
6. **历史 KPI 相关性**（AMZN 案例）

**倍数分析三维度**：
1. **这只股票过去交易在哪里**——绝对 & 市场相对
2. **这只股票相对同业交易在哪里**——当前价差 & 历史价差
3. **这个倍数在绝对意义上隐含什么**——市场隐含的增长算法、相对 S&P 500 的基本面

**市场相对特征** `[M11 p.73]`："如果市场以 18x 交易，对应平均 5% 收入增长与 8% EPS 增长，那是我估值的中心基准。" 增长更快、质量更高的生意应比市场贵；更慢、更低的应更便宜。

**同业相对倍数告诉你内嵌的预期** `[M11 p.72]`：MedTech NTM P/E vs 有机收入增长——MedTech 1 26.0x / 12.0%；MedTech 2 24.0x / 8.0%；MedTech 3 22.0x / 7.0%；MedTech 4 14.0x / 4.0%；**Avg 21.5x / 7.8%**；MedTech 5 为 18.0x ⇒ **"市场在告诉我们 MedTech 5 预期的有机收入增长是多少？如果我们相信 MedTech 5 有路径达到 MedTech 3 的有机增长呢？"**

**可比公司表结构** `[M11 p.71]`：PRICE | MCAP | EV | 3M ADV | EV/REVENUE (2023/2024/2025) | EV/EBITDA (2023/2024/2025) | P/E (2023/2024/2025)；16 家 medtech 按卖方 2025 EV/EBITDA 排名（TNDM → BAX），AVG 行：EV/Rev **6.4x / 5.8x / 5.3x**；EV/EBITDA **9.4x**（2023 平均）；P/E **141.8x / 20.2x**（2023 平均）。

### 1.15 正常化盈利与未来状态 `[M11 p.97–109]`

**要正常化什么？** `[M11 p.104]`：
1. **中周期/正常化收入**（剔除大的收入逆风或顺风）
2. **正常化利润率**（小心把倍数施加在峰值或谷值利润率上）
3. **资本结构**（若公司在偿债，要考虑；若高息负债可再融资，也要考虑）
4. **正常化资本密集度**（折旧 vs capex 的差额）

**方法一：正常化价格计算** `[M11 p.100]`：Normal Multiple **20.0x** × Normal EPS **$1.24** = Normalized Price **$24.80**；第 3 年按 **15.0%** 折现 ⇒ **Discounted Normalized $16.31**。（案例：收入 $100→$65（**−35%**）后复苏；利润率 20%→5%→10%→15%→20%；EPS $1.13 → ($0.13) → $0.21 → $0.68 → $1.24 → $1.32；**"一次难看的收入冲击需要 3 年才能完全恢复；利润率也需要 3 年。"**）

**未来状态盈利（超高增长名字）** `[M11 p.102]`：收入年增 25%、亏损、第 5 年才开始赚钱。Normal Multiple **25.0x** × Normal EPS **$4.20** = Normalized Price **$105.07**；第 4 年按 **15.0%** 折现 ⇒ **Discounted Normalized $60.07**。

**AMZN 正常化盈利** `[M11 p.98]`："AMZN 是便宜（2x EV/Rev）还是贵（200x P/E）？取决于你对正常化的看法。" 当前价 $103.40；'24 Normalized EPS **$5.08** ⇒ P/E **20.4x**；Target P/E **35.0x** ⇒ Target Price **$177.73** ⇒ **上行 71.9%**。分部模型：North America / International / AWS 的销售与经营利润；AWS 经营利润率 26.3% → 30.0%。

**COATUE 框架** `[M11 p.103]`："聚焦 TAM、盈利、增长，以及 5–7 年后的对应 P/E"；"公众投资者并不总像私募投资者那样有想象力。"

**折现未来状态** `[M11 p.108]`：看向 3–7 年后时，权益成本很重要；**典型市场权益成本 8–12%**；但 alpha 导向的投资者感知资本成本更高。两种做法：(a) 未来状态达到 **15–20%+ 的 IRR 门槛**；(b) **用机会成本折现未来状态** —— *"我更喜欢这个方法，因为它更容易比较 '5 年视角' 交易与 '1 年视角' 交易。"*
> **"Be careful using a normalized multiple well above 25x. Most assets 'in maturity' will not trade well above 25x (there are exceptions). I typically use 12–20x depending on the asset."**

**未来状态盈利的优点与缺点** `[M11 p.109]`：优点——提供更好的基线 EPS 用于资本化；被机构基本面投资者使用。缺点——"谁知道 5 年后的 EPS 长什么样？什么都可能发生"；"'正常化盈利'的押注可能非常不稳定，因为基线的感知会漂移。"

### 1.16 前瞻 IRR 与"三年翻倍" `[M11 p.111–112]`

- **前瞻 IRR**：IRR = 内部收益率。"我把前瞻 IRR 理解为可能的'交易走廊'或股票大概率的主要方向。" 若一只股票提供 20% 的 IRR，它仍可能 6 个月纹丝不动，但主要方向是向上向右——**6 个月的横盘实际上会扩大 IRR**。
- **用 P/E × EPS 分解 IRR 的驱动**：(1) EPS 增长，(2) P/E 修正。
- 算例：3 年后 EPS $1.00 @ 10.0x = $10.00 → EPS $1.33 @ 15.0x = $20.00 ⇒ **IRR 26.0%**。
- **"三年翻倍"（26% IRR）的三条路径**：
  1. **巨大的 P/E 扩张**（10.0x → 20.0x，EPS 持平 $1.00）——但股票不会无缘无故翻倍 P/E
  2. **巨大的 EPS 增长**（40.0x → 40.0x，EPS $1.00 → $2.00）——很少有股票 EPS 增长 26%，而高 P/E 面临 P/E 收缩风险
  3. **低/合理的起始 P/E + 隐藏/被低估的 EPS 增长，且能在复利之上再享受 P/E 扩张**（10.0x → 15.0x，EPS $1.00 → $1.33）—— **三条中最优**
- Robertson 名言（Sebastian Mallaby, *More Money Than God*）："他的 idea investment——一个绝妙的投资，按 Robertson 的说法——是那种可能在三年里翻倍的东西。如果 Robertson 相信他找到了这样一个投资，他愿意咬紧牙关持有，直到世界追上他的分析。"

### 1.17 风险/回报（Risk / Reward）`[M11 p.113–125]`

**Reward/Risk 网格（当前价 $50.00）** `[M11 p.113]`：

| | Reward | Risk | R/R |
|---|---|---|---|
| NTM EPS $3.00 | $56.00 (42.9%) | $45.00 (31.1%) | 1.1x |
| NTM2 EPS $4.00 | $57.00 (40.4%) | $34.45 (39.6%) | 1.0x |
| Reward P/E 20.0x | $80.00 (60.0%) | $53.00 (35.0%) | 1.5x |
| Risk P/E 13.0x / Risk EPS $2.65 | | | 2.4x–2.9x |
| **12m Reward Price $80.00 / % return 60.0%** | | | **1.9x** |

- **奖励通常这样计算**：**NTM-2 EPS × 目标 NTM-P/E（12 个月后）**。**NTM2 = 12 个月后的未来 12 个月 EPS**（前瞻季度 5+6+7+8）。为简洁、一致与授权匹配，基础 Reward 统一用 12 个月预测。
- **风险情景是近期风险**（"如果事情变得棘手，股票近期能到哪里"）——通常是**更低盈利水平上的弱/谷值 P/E**。
- **"Generally 2.0x is hurdle on the buy, with 3.0x being a table-pounding level."**（**2.0x 是买入门槛，3.0x 是拍桌级别**。）

**构建奖励情景** `[M11 p.114]`：
- 选定时间框架（可以是 2 个月或 2 年，但**选一个，并对所有股票用一致的时间框架**）。
- 对一只股票的基础分析包括：**3 年 IRR**（长期可能方向）、**12m Reward**（12 个月内股票能到哪）、**12m Risk**（未来 12 个月内股票最差能到哪——"我为了拿到 Reward 所承担的风险"）。
- 12m reward 算式：起点 = NTM EPS × NTM P/E；**12m Reward = NTM2 EPS × NTM2 P/E**。

**Reward、Risk 与 R/R** `[M11 p.115]`：常见买方问题："风险回报是多少？""上行下行各是多少？" PM 想知道 (1) 我对了赚多少，(2) 我错了亏多少。"有经验的投资者知道没有所谓'稳赚'，并且倾向于概率化思考（好的那些至少如此）。"
> **"Take care case of the risk case and the reward will take care of itself."**
算例：2024 EPS **$3.83** × Target P/E **35.0x** = EOY Target **$134.08**，回报 **55.9%**；Risk case 2023 EPS **$2.10** × **32.0x** = **$67.20**，风险 **(21.9%)** ⇒ **R/R 2.6x**。

**构建风险情景** `[M11 p.116]`：仔细分析什么会让这笔投资出错。
- **股票下跌的三条路**：(1) 盈利预测下降；(2) 估值倍数下降（更高风险/情绪、终值悬顶、增长放缓、预期利润率收缩、资本密集度上升的代理）；(3) 稀释（发行可转换债或增发股权）。
- 构造诚实的风险情景：研究历史（过去衰退期发生了什么？）；研究历史 NTM P/E 图（P/E 在哪里触底？什么环境造成的？）；问管理层他们怎么看。

**思考风险情景的方式** `[M11 p.117]`：谷值 P/E（绝对或相对）；谷值 EV/EBITDA；谷值利润率；谷值收入；流动性状况（自筹资金型生意 ⇒ 风险情景不那么严重）；若未盈利——熊市情景的现金消耗 vs 资产负债表现金（现金跑道）；EV/Rev 或 EV/GP 倍数；资产支撑？并购支撑？

**波动率作为风险情景代理** `[M11 p.119]`：
> **"A 20% vol name shouldn't have a +40%/-5% R/R."**
年化波动率是"1-sigma 风险情景下股票能到哪"的好代理。校准：Reward **40.0%** / Vol **20.0%** ⇒ **R/V 2.0x**；Reward **60.0%** / Vol **30.0%** ⇒ **R/V 2.0x**。

**风险情景纪律** `[M11 p.120]`：仔细分析什么会让投资出错；理解管理层会如何反应；拥抱广泛的结果区间；**不要合理化、不要自满**；**"有罪推定（Guilty until proven innocent）"**；**"第一次 miss 很少是最后一次 miss"**；理解隐含的赌注；下行估值支撑。

### 1.19 3R 与心智模型 `[M11 p.127–134]`

**THE 3 R'S**：

| R | 含义 |
|---|---|
| **ROLL-FORWARD（滚动）** | 延长 "E" 的久期，即把 "E" 滚动 1–3 年 |
| **REVISIONS（修正）** | 一致预期 "E" 上调或下调 |
| **RE-RATING（再定价）** | 施加在 "E" 上的 P/E 上调或下调 |

**回报预测的三种心智模型** `[M11 p.128]`：P/E × EPS = 价格；作为选股者我们是价格预测者；**1 年预测需要预测 NTM+2 EPS 与 NTM+2 P/E**。**三种"赚钱方式"**：(1) EPS 增长、P/E 滚动（复利型）；(2) EPS 修正；(3) P/E 上行或下行。

| 模型 | Start | End | 价格回报 | EPS 回报 | P/E 回报 |
|---|---|---|---|---|---|
| **VALUE STOCK（价值股）** `[M11 p.129]` | 5.0x, $1.00, $5.00 | 9.0x, $1.10, $9.90 | +80.0% | +10.0% | +80.0% |
| **GROWTH STOCK（成长股）** `[M11 p.130]` | 100.0x, $1.00, $100.00 | 50.0x, $4.00, $200.00 | +100.0% | +300.0% | (50.0%) |
| **COMPOUNDER（复利股）** `[M11 p.131]` | 20.0x, $1.00, $20.00 | 20.0x, $2.00, $40.00 | +100.0% | +100.0% | 0.0% |

**P/E roll-forward / 复利法** `[M11 p.132]`：分析师通常思考 NTM 或日历年 P/E（秋季切换到次年）。理论：**若股票维持其 NTM 倍数且 EPS 高比例复利，你就能搭 EPS 增长的免费便车**。算例 2019→2020：EPS $1.00→$1.10（+10%），P/E 10.0x→10.0x，Target $10.0→$11.0，回报 **+10.0%**。

| Normalized inorganic revenue growth | 1.0% | 2.5% | 1.8% |
| Normalized revenue growth | 3.5% | 7.5% | 5.5% |
| Normalized op profit growth | 5.0% | 10.0% | 7.5% |

### 1.20 估值门槛（The Valuation Bar）：META 案例 `[M11 p.145–153]`

- **META NTM P/E**：10.5x（'22）→ **6.6x（'25）**（低倍数）。
> **"STOCKS ASK DIFFERENT QUESTIONS AT DIFFERENT PRICES."**（股票在不同价位问不同的问题。）

**在 $130 时** `[M11 p.148]`：市场在折现 **LSD/MSD 的收入下滑 + 实质的利润率恶化 + capex 的永久性上台阶** ⇒ 30 年 DCF = **$131.32**（回报 **(1.2%)**）；PF of FCF $310,607.5；PV of TV $5,165.0；Total PV $315,772.5；Less Net Debt ($40,489)；Present Value of Equity $356,261.5；**Value per share $131.32**；TV 10.0x；WACC 8.0%；DCF 价值对应 P/E：'22 10.3x、'23 9.8x、'24 8.4x、'25 6.6x；当前价对应 P/E：'22 10.5x、'23 9.9x。

**META P/E 收缩的教训** `[M11 p.149]`：
- **业务动能很重要（Business momentum matters）**：投资者没有 30 年的水晶球，所以当前业务趋势是预测远期现金流的最佳基线。**加速时 P/E 倾向上升；减速时 P/E 倾向下降。**
- **对终值的感知可能很善变（fickle）**：在 25x P/E 时，META 隐含了有意义的终值；在 10x 时则不再隐含。**业务动能减速、TikTok 的兴起、资本密集的元宇宙赌注**共同施压估值。

**如何使用这个方法** `[M11 p.150]`：什么被计入股价？我相信会发生什么？当我的结果兑现时，市场会如何外推它？→ **构建情景树。**

### 3.11 DCF 交付前自检 `[M11 p.20–26, p.35, p.104]`

- [ ] 终值占 NPV 的比重是否已披露？（**典型 5 年模型 ≈ 85%**）
- [ ] 是否用了 30 年分段递减模型把价值推进预测期？（否则说明 50–100bps 的终值增长假设在决定结论）
- [ ] WACC 的三项输入（无风险利率、Beta、ERP）是否都做了敏感性披露？（**±100–200bps**）
- [ ] 有杠杆/无杠杆口径是否匹配（**EV/Net Income、P/EBITDA、L-FCF/EBITDA 一律判错**）？
- [ ] 净债务、优先股、合资、租赁、诉讼负债是否已从 EV 扣除？
- [ ] 收入、利润率、资本结构、资本密集度是否已正常化（非峰非谷）？
- [ ] 施加的倍数是否隐含了可辩护的增长与持续年限（**10x ⇒ 不增长持续 25–35 年**）？

### 3.12 DCF 八项错误逐条审计（Mauboussin 清单）`[DCE p.2–8]`

对照检查自己的模型（或你看到的模型）。**若出现其中一条，该模型对商业判断几乎毫无信息量。**

- [ ] **1 预测期够长吗？** 显式期 **≥ 5 年**（许多公司需 **> 10 年**），且**理想情况下捕捉 ≥ 1/3 的公司价值**；价值有没有被"倾倒"进终值？
- [ ] **2 终值经济上合理吗？** 终值是否反映**价值中性期**（ROI 回归资本成本）？施加在 EBITDA 上的倍数**隐含什么**？（**13.0x ⇒ 永续 6% 盈利增长 + 150% 增量资本回报** ⇒ 荒谬）永续法下终值占公司价值 **60–70%** 是否可接受？
- [ ] **3 资本成本说得通吗？** Beta 与 ERP 是否过时/循环？**长期模型用几何平均 ERP**（1.9pp / 3.7pp / 6.2pp 三个窗口）；**ERP 取 3–4pp ⇒ 市场长期回报约 8%**；**+200bps 还是 +600bps 会显著改变输出**；是否已用**价值驱动因子情景**替代资本成本敏感性网格？
- [ ] **4 增长与投资挂钩了吗？** 模型里**是否有一行 ROI**？ROI 是否在无战略性理由时大幅波动？并购驱动的增长率是否只配了现有业务的资本开支？
- [ ] **5 其他负债处理了吗？** **员工期权：已授予 → 或有负债；用基本股数；未来授予 → 费用**；养老金、其他离职后福利是否已按行业重要性处理？
- [ ] **6 打了私募折价吗？** 若打了 20–25% 折价，**协同/催化剂是否已单独建模并与独立业务估值分开**？
- [ ] **7 有重复计算吗？** **回购**（现金流估值 + 缩减股数）、**利息收入 + 现金余额**、**扣融资成本 + 扣债务**——逐一排查。
- [ ] **8 情景够多吗？** 是否**只有一个情景**却把目标价钉在上面？**敏感性网格是否只覆盖资本成本/增长/终值**（而非销售/利润率/投资需求）？**驱动因子之间的交互作用**是否被考虑？是否做了**对期望值的适当折现（安全边际）**？

### 3.13 估值方法选择规则（结合实务调查基线）`[Survey p.5–7]`

**默认起点（多数情形）**：**倍数法为主（实务中 92.8% 的分析师使用，实际应用频率 64%）**，主力工具是 **P/E（88.1%）与 EV 倍数（76.7%）**；**DCF（现值折现）作为交叉验证与差异化认知的来源**（78.8% 使用，实际频率 47%）。

| 情形 | 首选方法 | 依据 |
|---|---|---|
| 盈利稳定、前瞻可估 | **P/E（分母用前瞻净利，占实务 61.1%）** | Survey p.6；M11 p.50 |
| 折旧/摊销极高、几乎无 EPS（医院、酒店） | **EV/EBITDA** | M11 p.87；Survey p.6（88.3% 首选 EBITDA） |
| 尚未盈利 | **EV/Sales（必须配利润率结构）** | M11 p.83–85 |
| opex 暂时偏高 | **EV/GP** | M11 p.86 |
| 盈利被一次性项目扭曲 | **正常化 EPS** | M11 p.97–109 |
| 收购是潜在结果 | **Takeout value** | M11 p.49 |
| 需要内在价值锚 / 有差异化认知 | **DCF（FCFF 模型，两阶段以上，实务逐期均值 7.77 年）** | Survey p.7, p.9；DCE p.2 |
| 周期性 | **CAPE 或正常化盈利** | MB-PE p.20；M12 p.35–38 |
| 金融股 | **P/B 体系**（实务中 P/B 为第三常用倍数，59.0%） | Survey p.5–6 |

**口径纪律**（每次用倍数前过一遍）：
- 有杠杆 vs 无杠杆：**"Match unlevered to unlevered. Match levered to levered."** `[M11 p.78]`
- **10x ⇒ 不增长、持续 25–35 年；15x ⇒ 约 5% 增长、持续 25–35 年** `[M11 p.51]`
- **前瞻 vs 追溯**：前瞻净利 61.1% vs 追溯净利 8.8% `[Survey p.6]`
- **一次性项目被资本化**：市场在一次性 EPS 上付 35x `[M11 p.52]`

## 4. 常见错误与陷阱（Common Mistakes / Pitfalls）

1. **把内在价值当法律而非感知** `[M11 p.8]`。框架影响行为，但感知可以差异极大。
2. **用 5 年 DCF + 单一终值增长率** —— 约 **85%** 的价值坐在终值里；终值增长率概念上极难（长期增长、企业失败率、增长阶段、周期性），**50–100bps 决定生死**。应改用 **30 年 DCF + 分段递减 + ex-growth 终值倍数** `[M11 p.23–26]`。
3. **把 WACC 当精确值** —— 五个不可靠理由：单因子 beta 模型；CAPM 把股权现金流视为合约化（并非如此）；无风险利率口径不明；**5% ERP 是循环论证**；**100–200bps ⇒ 截然不同结果** `[M11 p.35]`。
4. **忽略终值感知风险** —— 同一家公司在 **25x vs 10x** 处隐含了截然不同的终值；这是 META 的教训 `[M11 p.149]`。
5. **轻率地施加倍数** —— "Don't apply multiples lightly!"；**20x 倍数隐含增长 + 持续数十年** `[M11 p.51, p.107]`。
6. **有杠杆/无杠杆口径错配** —— **EV/Net Income、P/EBITDA、L-FCF/EBITDA 是错误的**。**"Match unlevered to unlevered. Match levered to levered."** `[M11 p.78]`
7. **忘记扣净债务/非股权索取权** —— 优先股、合资、租赁会计，**以及诉讼负债** `[M11 p.79]`。
8. **把峰值或谷值利润率资本化** —— 先正常化收入、利润率、资本结构与资本密集度 `[M11 p.97, p.104]`。
9. **使用远高于 25x 的正常化倍数** —— 成熟资产很少持续高于 25x；**典型区间 12–20x** `[M11 p.108]`。
10. **数字对但倍数错** —— **"一只股票 80% 的涨幅来自倍数"**；你可能算对数字而股价反向 `[M11 p.65]`。
11. **低估风险情景** —— **"第一次 miss 很少是最后一次 miss"**；把风险情景照顾好，回报会自己照顾自己 `[M11 p.115, p.120]`。
12. **混淆"好公司"与"好股票"** —— MSFT：1999→2016 收入 4.7x、EPS 4.0x，股价总回报却只有 **7.2%** `[M11 p.140]`。
13. **买进价值陷阱** —— BBBY 在 **6.8x P/E** 时归零；低 P/E 常常"看起来便宜"是有原因的（四象限错价矩阵：看起来便宜/真便宜、看起来便宜/真贵、看起来贵/真便宜、看起来贵/真贵）`[M11 p.5–7, p.142]`。
14. **在实践中使用股利折现模型** —— 按讲师的经历，精确使用次数为 **零** `[M11 p.27]`。
15. **认为 EPS ≠ FCF 没关系** —— **FCF/股的轨迹是衡量价值创造最好的指标**；EPS 只是代理 `[M11 p.30, p.88]`。
16. **用市场倍数但不看市场相对口径** —— 必须看市场相对倍数以调整 prevailing 市场水平 `[M11 p.70]`。
17. **不做回报分解** —— 区分 EPS 增长 / P/E 扩张 / 修正；**P/E 扩张是最短暂的一项** `[M11 p.135–137, p.128]`。
18. **预测期太短、把价值倾倒进终值** —— 卖方模型样本中预测期**通常 5 年或更短**；这迫使把价值堆到终值上，产生完全不经济的持续价值 `[DCE p.2–3]`。
19. **重复计算** —— 模型给现金流估值（一次），又用同一现金流缩减股数（回购）；或把利息收入计入现金流并同时把现金加进企业价值 `[DCE p.7]`。
20. **只给一个 DCF 情景** —— 分析师常把目标价钉在单一情景上；**投资是概率性的，一个情景不构成周密分析** `[DCE p.7–8]`。
21. **用敏感性网格代替情景分析** —— 网格只覆盖资本成本/增长/终值假设，**对理解业务前景几乎无信息量**；且**忽略驱动因子之间的交互作用** `[DCE p.7–8]`。
22. **把公开市场价值打 20–25% 折价** —— 把基准现金流与协同现金流混为一谈，通不过透明性检验 `[DCE p.7]`。
23. **不把增长与价值创造挂钩** —— 只在模型里加一行 ROI 做检查：**ROI 在无战略性理由时大幅波动 ⇒ 模型不可靠** `[DCE p.6]`。
24. **对盈利不做成分甄别** —— "什么算非经常或非经营，完全取决于观察者的眼睛"；**永久性/过渡性/价值无关**三分法是最小防御 `[MB-PE p.13]`。
25. **把 SBC 当"免费"** —— 成本只在附注披露、不计入盈利；完全稀释股数又捕捉不到负债规模 ⇒ **P/E 与 EV/EBITDA 都会系统性高估** `[MB-PE p.9；DCE p.6–7]`。
26. **把 adjusted EBITDA 当 GAAP** —— **调整平均抬高 EBITDA 13.7%**；EBITDAR/EBITDAC/EBITDAX 等变体泛滥使跨公司比较失效 `[MB-EV p.4, p.17]`。
27. **用 EV/EBITDA 忽略经营杠杆** —— 倍数不显式反映风险；**高经营杠杆的生意对销售变化极度敏感** `[MB-EV p.5]`。
28. **用 PEG 做选股** —— PEG 的分子就是 P/E；**在 P/E 与任意短期盈利增长预测之间没有经济上可靠的关联** `[MB-PE p.13–14]`。
29. **无情景地使用倍数** —— 建议显式预测期 **≥ 5 年**（许多公司需 **> 10 年**），且**理想情况下捕捉至少 1/3 的公司价值** `[DCE p.2]`。

## 5. 关键词汇（Key Vocabulary）

| 术语 | 课程定义 |
|---|---|
| Price is a FCF forecast | 价格等于市场对 FCF 的折现预测 |
| Multiples as shorthand | "Multiples are a short-hand for DCF" / "everything is a DCF"（Mauboussin） |
| Garbage in, garbage out | DCF 对资本成本与终值假设的敏感性 |
| Equity duration | 达到今天价格所需的 FCF 折现年数（标准股权 **25–35 年**） |
| Terminal value (TV) | 预测期之外的价值；永续增长率法或退出倍数法 |
| Exit multiple | 对最终年 FCF 施加倍数的 TV 方法 |
| Implied multiple | DCF 所隐含的倍数；此处 2.5% g / 8% WACC 下为 **18.6x** |
| WACC | 加权平均资本成本：Ke × E/V + 税后债务 YTM × D/V |
| CAPM | Cost of Equity = Rf + Beta × ERP |
| ERP | 股权风险溢价；惯例上用恒定 **5%** |
| Betting against beta | 高 Beta 名字并不带来更高回报的证据 |
| Market relative characteristics | 相对市场的增长/质量特征给股票估值 |
| Implied multiple / implied P/E | 市场在当前价格上支付的 P/E |
| Earnings power | 市场定价机制在寻找的正常化盈利 |
| Reverse P/E | 价格 ÷ 历史 P/E = 隐含的正常化盈利能力 |
| Normalized earnings | 中周期收入、利润率、资本结构、资本密集度 |
| Future state earnings | 看向 3–7 年后；按权益成本折回 |
| Incremental margin | 下一美元收入带来的利润率（自然上限） |
| Prospective IRR | 大概率的"交易走廊"/主要方向 |
| 3-year double | 100% 三年回报（**26% IRR**）的三条路径 |
| Roll-forward | 把 "E" 延长 1–3 年 |
| Revisions | 一致预期 "E" 上调或下调 |
| Re-rating | 施加在 "E" 上的 P/E 上调或下调 |
| Value stock / Growth stock / Compounder | 三种回报心智模型 |
| The algorithm | 3–5 年正常化 EPS 增长，沿利润表推演 |
| P/E cycle | 在历史 P/E 区间低端买、高端减仓 |
| Terminal value perception | 市场内嵌终值观点的变化；驱动 P/E 波动 |
| Valuation bar | 某个价格下市场计入了什么；"股票在不同价位问不同的问题" |
| Reward | 12m Reward = NTM2 EPS × NTM2 P/E |
| Risk | 12m Risk = 近期下行（更低盈利上的谷值倍数） |
| R/R | Reward/Risk；**2.0x 门槛，3.0x 拍桌级** |
| Probability tree | 概率加权的多情景价值 |
| TV perception risk | 终值感知波动大的股票估值波动大得多 |
| Takeout value | 收购交易中的每股价值 |
| EV/GP | 毛利的 EV 倍数——调整可自由支配 opex |
| FCF yield | FCF/市值（有杠杆）或 UL-FCF/EV（无杠杆）；回收期代理 |
| COATUE framework | 聚焦 TAM、盈利、增长及 5–7 年后的对应 P/E |
| Economically sound & transparent | DCF 模型的判据：回报/增长模式与行业地位及均值回归一致 + 你理解所选方法的经济含义 `[DCE p.2]` |
| Value creation vs value neutrality | DCF 分段：显式期捕捉超额回报（价值创造），终值反映耗尽增量机会后的价值 `[DCE p.3]` |
| Value dump（价值倾倒处） | 预测期过短迫使建模者把价值堆进终值 `[DCE p.2]` |
| ROIIC | 增量投资回报率；`Value = NOPAT_(CAP+1)×(1−g/ROIIC)/(WACC−g)`；ROIIC = WACC 时坍缩为永续 `[DCE p.9–10]` |
| Double counting | 同一美元价值被计算两次（如回购）`[DCE p.7]` |
| Public market discount | 公开市场价值打 20–25% 折价（通不过透明性检验）`[DCE p.7]` |
| Variant perception | 市场对某公司给出错误估值的有根据的信念 `[DCE p.8]` |
| Conditional frequency | 某方法的使用者中，用它做多大比例估值案例的均值；> 50% 为通用工具 `[Survey p.5]` |
| Present discounted value (PDV) | 调查中的现值折现法分类：78.8% 受访者使用 `[Survey p.5]` |
| FCFF vs FCFE | 企业自由现金流 vs 权益自由现金流；实务中 **FCFF 使用率几乎是 FCFE 两倍** `[Survey p.9]` |
| Permanent / transitory / value-irrelevant earnings | 盈利三分法（Revsine, Collins & Johnson）：永久性、过渡性、价值无关 `[MB-PE p.13]` |
| Big-bath accounting | 把大量重组费用一次性计入，令"永久性盈利"被侵蚀 `[MB-PE p.8]` |
| Adjusted EBITDA | 非 GAAP 口径：剔除重组/减值并加入协同与预期成本节约；**平均抬高 EBITDA 13.7%** `[MB-EV p.4]` |
| EBITDAR / EBITDAC / EBITDAX 等变体 | 加入租赁、收购费用、勘探成本等的 EBITDA 变体，破坏跨公司可比性 `[MB-EV p.17]` |
| Operating leverage | 经营利润变动% ÷ 销售变动%；商业风险的合适度量 `[MB-EV p.5]` |
| CAPE | 周期调整后 P/E：用整个周期平均盈利做分母 `[MB-PE p.20]` |
| "Bullshit earnings" | 芒格对 EBITDA 的评价 `[MB-EV p.4]` |
